## Install with the install script

```bash
curl -fsSL https://install.villagesql.com | bash
```

The script asks which codebase to install (MySQL 8.4, Percona Server 8.4, or MySQL 9.7) and how to install it: a prebuilt download, Docker, or a source build. A prebuilt install goes under `~/.villagesql/` and starts the server on port 3306. Run it as a regular user: as root it exits with `Error: Running this installer as root is not supported.`

Where there is no terminal to answer the questions — a CI job, a Dockerfile with a non-root `USER`, an AI agent — pass the answers instead. Set them on the `bash` side of the pipe:

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=mysql-8.4 INSTALL_METHOD=prebuilt bash
```

`VSQL_CODEBASE` takes `mysql-8.4`, `percona-8.4`, or `mysql-9.7`. `INSTALL_METHOD` takes `docker`, `prebuilt`, or `source`. A source build also needs `VSQL_VERSION=stable|nightly|latest`; Docker and prebuilt installs are always the stable release.

To connect and install your first extension, see [Install](/en/8.4/stable/install-server#step-2-connect-to-the-server).

MySQL has a lot of surface area. These guides focus on the parts that come up most — from decisions you'll make once before your first migration to techniques you'll reach for every week. Each one is practical and works with VillageSQL.

New to SQL? The [MySQL tutorial](/en/tutorial/index) teaches it in order, one lesson at a time, against a single sample database. If you already write SQL, start with [choosing data types](/en/guides/choosing-data-types), [joins](/en/guides/joins), and [indexes](/en/guides/mysql-indexes) — they cover the fundamentals that everything else builds on.

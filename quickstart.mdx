## Install with the install script

```bash
curl -fsSL https://install.villagesql.com | bash
```

The script asks which codebase to install (MySQL 8.4, Percona Server 8.4, or MySQL 9.7) and how to install it. It installs the server under `~/.villagesql/` and starts it on port 3306.

For Docker, a source build, and your first extension, see [Install](/mysql-8.4/stable/quickstart).

## Set up your coding agent

<AgentSetup />

To add only the VillageSQL agent skills to your coding agent, run:

```bash
curl -sSL https://villagesql.com/skills | bash
```

The skills install a server, answer questions from these docs, and build or port extensions. See [Agent Skills](https://villagesql.com/agent-skills) for the list.

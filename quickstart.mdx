## Install with the install script

```bash
curl -fsSL https://install.villagesql.com | bash
```

The script asks which codebase to install (MySQL 8.4, Percona Server 8.4, or MySQL 9.7) and how to install it: a prebuilt download, Docker, or a source build. A prebuilt install goes under `~/.villagesql/` and starts the server on port 3306.

To connect and load your first extension, see [Install](/mysql-8.4/stable/install-server#step-2-connect-to-the-server).

## VillageSQL Server란 무엇인가요?

VillageSQL Server는 에이전틱 AI 시대를 위한 확장 기능을 갖춘 MySQL의 드롭인 대체품입니다. 확장 프레임워크를 통해 누구나 허락을 구하지 않고, 서버 코드를 변경하지 않고도 사용자 정의 데이터 유형과 사용자 정의 함수를 서버에 추가할 수 있습니다.

## MySQL용 확장 기능
확장 기능은 실행 중인 VillageSQL 서버에 기능을 추가합니다. 확장 기능이 추가할 수 있는 것:
- **사용자 정의 데이터 유형:** `UUID`, `COMPLEX`, `INET` 같은 InnoDB 열용 새 유형으로, 내장 유형처럼 사용합니다.
- **사용자 정의 함수:** C++ 또는 Rust로 작성하여 SQL에서 호출하는 함수입니다.

확장 기능은 SQL로 추가하고 제거합니다: `INSTALL EXTENSION`과 `UNINSTALL EXTENSION`.

설치할 수 있는 확장 기능은 [확장 기능 카탈로그](/ko/extensions/catalog)를 참조하세요.

### 확장 기능 빌드하기
[확장 기능 템플릿](https://github.com/villagesql/vsql-extension-template)으로 시작하고 [C++ 가이드](/guides/cpp-extensions) 또는 [Rust 가이드](/guides/rust-extensions)를 따르세요. AI의 도움을 받는 안내형 워크플로를 원한다면 [Extension Builder](https://villagesql.com/agent-skills)를 사용해 보세요.

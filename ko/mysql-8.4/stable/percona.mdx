VillageSQL은 **Percona Server** 기반으로도 빌드됩니다. Percona Server는 MySQL과
소스 호환되는 포크이며, 자체 스토리지, 성능, 관측 기능을 추가합니다.

## 이 빌드란 무엇인가 {#what-this-is}

업스트림 MySQL 8.4 대신 Percona 8.4 코드베이스를 기반으로 빌드한 VillageSQL
서버입니다. VillageSQL 확장 프레임워크와 그 SQL 명령, 확장은 두 빌드에서 동일하게
동작합니다 — Percona 빌드는 동일한 VillageSQL 표면 아래에 다른 기반을 둔 것입니다.

VillageSQL은 Percona 자체 기능을 문서화하지 않습니다. Percona Server 자체에 관한
내용 — 스토리지 엔진, 튜닝 옵션, 구성 — 은
[Percona 공식 문서](https://docs.percona.com/percona-server/8.4/)를 참조하세요.

## Percona 빌드 식별하기 {#identifying-a-percona-build}

Percona 빌드는 버전 문자열에 다른 코드베이스를 보고합니다:

```sql
SELECT @@villagesql_server_version;
-- Example output: percona-8.4_0.0.6
```

이 변수의 의미는 [시스템 참조](/ko/mysql-8.4/stable/reference#villagesql_server_version)를
참조하세요. VillageSQL은 한 코드베이스(예: `mysql-8.4`)의 데이터 디렉터리를 다른
코드베이스(예: `percona-8.4`)를 실행하는 서버로 업그레이드하는 것을 거부합니다.

## 설치 {#installing}

Percona 빌드는 MySQL 8.4 빌드와 함께 제공되며, 세 가지 설치 방법 모두에서 선택할 수 있습니다.

**설치 스크립트** 첫 번째 질문에서 **Percona 8.4** 를 선택하세요. 터미널이 없는 환경에서는 환경 변수로 직접 지정합니다.

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=percona-8.4 INSTALL_METHOD=prebuilt bash
```

**Docker** 이미지는 코드베이스별, 아키텍처별로 배포됩니다.

```bash
docker run -d --name vsql -e MYSQL_ALLOW_EMPTY_PASSWORD=yes -p 3306:3306 villagesql/server:percona-8.4_0.0.6-$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/')
```

**릴리스 다운로드** [0.0.6 릴리스](https://github.com/villagesql/villagesql-server/releases/tag/release/0.0.6)의 `villagesql-dev-server-percona-8.4_0.0.6-<os>-<arch>.tar.gz` 파일은 Linux 의 x86_64 와 aarch64, macOS 의 arm64 를 지원합니다.

**소스** `percona-8.4` 브랜치를 빌드하세요. 릴리스가 제공한 코드를 그대로 빌드하려면 `publish/percona-8.4_0.0.6` 태그를 사용하세요. 빌드 절차 자체는 [소스에서 빌드](/ko/mysql-8.4/stable/source)를 참조하세요.

데이터 디렉터리는 그것을 만든 코드베이스에 속합니다. VillageSQL 은 `mysql-8.4` 데이터 디렉터리를 `percona-8.4` 서버로 열지 않으므로, 기존 디렉터리를 가리키지 말고 이 빌드를 전용 디렉터리에 설치하세요.

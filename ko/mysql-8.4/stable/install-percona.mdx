Percona 빌드는 MySQL 8.4 빌드와 함께 제공됩니다. 설치 스크립트, Docker 또는
소스 빌드로 설치하세요.

**설치 스크립트, 터미널에서.** 스크립트를 실행한 다음, 첫 번째 질문에서
**2) Percona 8.4** 를 선택하세요:

```bash
curl -fsSL https://install.villagesql.com | bash
```

**설치 스크립트, 터미널 없이.** CI 작업, Dockerfile, AI 에이전트에서는
파이프의 `bash` 쪽에 코드베이스와 설치 방법을 지정하세요:

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=percona-8.4 INSTALL_METHOD=prebuilt bash
```

**Docker.** 이미지는 코드베이스별, 아키텍처별로 배포됩니다:

```bash
docker run -d --name vsql -e MYSQL_ROOT_PASSWORD=<your-password> -p 3306:3306 villagesql/server:percona-8.4_latest
```

**소스.** [소스에서 빌드](/ko/mysql-8.4/stable/source-percona)를 따르세요.

데이터 디렉터리는 그것을 만든 코드베이스에 속합니다. VillageSQL은 `mysql-8.4`
데이터 디렉터리를 `percona-8.4` 서버로 열지 않으므로, 기존 디렉터리를 가리키지
말고 이 빌드를 전용 디렉터리에 설치하세요.

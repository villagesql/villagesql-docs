## 설치 스크립트로 설치하기 {#install-with-the-install-script}

```bash
curl -fsSL https://install.villagesql.com | bash
```

스크립트는 어떤 코드베이스를 설치할지(MySQL 8.4, Percona Server 8.4, MySQL 9.7)와 어떤 방법으로 설치할지(사전 빌드 다운로드, Docker, 소스 빌드)를 묻습니다. 사전 빌드 설치는 `~/.villagesql/` 아래에 설치되며 포트 3306에서 서버를 시작합니다. 일반 사용자로 실행하세요. root로 실행하면 `Error: Running this installer as root is not supported.` 오류와 함께 종료됩니다.

질문에 답할 터미널이 없는 환경(CI 작업, root가 아닌 `USER`를 지정한 Dockerfile, AI 에이전트)에서는 답을 환경 변수로 전달하세요. 파이프의 `bash` 쪽에 지정합니다.

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=mysql-8.4 INSTALL_METHOD=prebuilt bash
```

`VSQL_CODEBASE` 는 `mysql-8.4`, `percona-8.4`, `mysql-9.7` 을 받습니다. `INSTALL_METHOD` 는 `docker`, `prebuilt`, `source` 를 받습니다. 소스 빌드에는 `VSQL_VERSION=stable|nightly|latest` 도 필요합니다. Docker 와 사전 빌드 바이너리 설치는 항상 안정 릴리스입니다.

서버에 연결하고 첫 번째 확장 기능을 설치하려면 [설치](/ko/8.4/stable/install-server#step-2-connect-to-the-server)를 참조하세요.

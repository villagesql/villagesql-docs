## 설치 스크립트로 설치하기 {#install-with-the-install-script}

```bash
curl -fsSL https://install.villagesql.com | bash
```

스크립트는 어떤 코드베이스를 설치할지(MySQL 8.4, Percona Server 8.4, MySQL 9.7)와 어떤 방법으로 설치할지(사전 빌드 다운로드, Docker, 소스 빌드)를 묻습니다. 사전 빌드 설치는 `~/.villagesql/` 아래에 설치되며 포트 3306에서 서버를 시작합니다.

서버에 연결하고 첫 번째 확장 기능을 로드하려면 [설치](/ko/mysql-8.4/stable/install-server#step-2-connect-to-the-server)를 참조하세요.

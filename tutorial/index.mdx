This tutorial teaches SQL on MySQL in order, one lesson at a time. It starts
with a single `SELECT` and finishes with transactions. Every lesson queries the
same sample database, so each one builds on the data you already loaded instead
of inventing new tables.

Read it in sequence if you are new to SQL. If you already write SQL and want
one answer to one question, the [MySQL guides](/guides/index) cover the same
ground organized by task rather than by lesson.

## What you need

A running server, the Sakila sample database loaded into it, and a client. The
three setup lessons cover all three.

## Where VillageSQL fits

VillageSQL is MySQL with an extension framework added, so every statement in
this tutorial runs on it unchanged. No lesson here needs an extension. Once you
finish, the [guides](/guides/index) cover what the extensions add on top.

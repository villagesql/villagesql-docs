Sakila arrives as 2 SQL files in one zip. The first builds the tables, the
second fills them. You run them in that order, against the server from
[Install a server](/tutorial/install-mysql).

## Download it

Run these in any directory you like.

```bash
curl -O https://downloads.mysql.com/docs/sakila-db.zip
unzip sakila-db.zip
```

That leaves a `sakila-db` directory. The 2 files you need from it are
`sakila-schema.sql` and `sakila-data.sql`.

## Load it

The schema file first, then the data file. Press Return at each password prompt
if `root` has no password.

```bash
mysql -u root -p < sakila-db/sakila-schema.sql
mysql -u root -p < sakila-db/sakila-data.sql
```

Neither command prints anything when it works. The data file takes longer,
because it inserts every row in the database.

<Note>
The schema file begins with `DROP SCHEMA IF EXISTS sakila`. Running these 2
commands again rebuilds the database from scratch, so you can always get back
to a clean copy. Anything you changed goes with it.
</Note>

## Check it

Ask the server what the database now contains.

```bash
mysql -u root -p -e "USE sakila; SHOW TABLES;"
```

The tables can arrive without the data, so count something as well.

```bash
mysql -u root -p -e "SELECT COUNT(*) FROM sakila.film;"
```


1,000 films means you are ready for the first lesson.

## Work inside the database

Every lesson writes its queries as though `sakila` is the current database.
Name it when you open the client:

```bash
mysql -u root -p sakila
```

Or switch to it once you are inside:

```sql
USE sakila;
```

Without one of those, a query naming `film` fails.

```bash
mysql -u root -p -e "SELECT COUNT(*) FROM film;"
```

```text
Enter password:
ERROR 1046 (3D000) at line 1: No database selected
```

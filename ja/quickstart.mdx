## インストールスクリプトでインストールする {#install-with-the-install-script}

```bash
curl -fsSL https://install.villagesql.com | bash
```

スクリプトは、どのコードベースをインストールするか (MySQL 8.4、Percona Server 8.4、または MySQL 9.7) と、どの方法でインストールするか (ビルド済みのダウンロード、Docker、またはソースビルド) を尋ねます。ビルド済みのインストールは `~/.villagesql/` の下に配置され、ポート 3306 でサーバーを起動します。

接続して最初の拡張機能を読み込むには、[インストール](/ja/8.4/stable/install-server#step-2-connect-to-the-server)を参照してください。

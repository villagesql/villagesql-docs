## インストールスクリプトでインストールする {#install-with-the-install-script}

```bash
curl -fsSL https://install.villagesql.com | bash
```

スクリプトは、どのコードベースをインストールするか (MySQL 8.4、Percona Server 8.4、または MySQL 9.7) と、どの方法でインストールするか (ビルド済みのダウンロード、Docker、またはソースビルド) を尋ねます。ビルド済みのインストールは `~/.villagesql/` の下に配置され、ポート 3306 でサーバーを起動します。スクリプトは一般ユーザーで実行してください。root で実行すると、`Error: Running this installer as root is not supported.` で終了します。

質問に答える端末がない場合 (CI ジョブ、root 以外の `USER` を指定した Dockerfile、AI エージェントなど) は、答えを環境変数で渡します。パイプの `bash` 側に指定してください。

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=mysql-8.4 INSTALL_METHOD=prebuilt bash
```

`VSQL_CODEBASE` は `mysql-8.4`、`percona-8.4`、`mysql-9.7` を受け付けます。`INSTALL_METHOD` は `docker`、`prebuilt`、`source` を受け付けます。ソースビルドでは `VSQL_VERSION=stable|nightly|latest` も必要です。Docker とビルド済みバイナリのインストールは、常に安定版リリースです。

接続して最初の拡張機能をインストールするには、[インストール](/ja/8.4/stable/install-server#step-2-connect-to-the-server)を参照してください。

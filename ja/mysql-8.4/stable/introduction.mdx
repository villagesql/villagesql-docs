**VillageSQL Server for MySQL** は、MySQL にそのまま差し替え可能な、オープンソースで拡張可能なトラッキングフォークです。

VillageSQL Server は、MySQL の堅牢な基盤を基に、強力な **拡張フレームワーク** を導入しています。このフレームワークにより、開発者は、アップストリームリリースを待ったり、複雑なフォークを維持したりすることなく、新しいデータ型や関数などのまったく新しい機能を追加できます。

このバージョンの VillageSQL は、MySQL 8.4.11 と互換性があります。このバージョンの Percona ビルドは、Percona Server for MySQL 8.4.11-11 を基にしています。

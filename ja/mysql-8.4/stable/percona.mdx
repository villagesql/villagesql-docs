VillageSQL は **Percona Server** 上にもビルドできます。Percona Server は MySQL とソース互換のフォークであり、独自のストレージ機能、パフォーマンス機能、および可観測性機能を追加しています。

## これは何か {#what-this-is}

アップストリームの MySQL 8.4 ではなく、Percona 8.4 のコードベースに対してビルドされた VillageSQL サーバーです。VillageSQL Extension Framework、その SQL コマンド、およびその拡張機能は、どちらでも同じように動作します。Percona ビルドは、同じ VillageSQL の表層の下にある異なる基盤です。

VillageSQL は Percona 独自の機能については文書化しません。Percona Server 自体に関すること (ストレージエンジン、チューニングオプション、構成など) については、[Percona の公式ドキュメント](https://docs.percona.com/percona-server/8.4/)を参照してください。

## 含まれていないもの {#what-is-not-included}

このビルドには、Percona の機能のうち 3 つが含まれていません。

**MyRocks** RocksDB ストレージエンジンはビルドされないため、`SHOW ENGINES` に `ROCKSDB` は表示されず、`rocksdb_*` システム変数も存在しません。このエンジンを指定したテーブルは失敗します。

```sql
CREATE TABLE t (i INT) ENGINE=ROCKSDB;
-- ERROR 1286 (42000): Unknown storage engine 'ROCKSDB'
```

Percona サーバーから取得したダンプのリストアは、このエンジンを指定した最初のテーブルで停止します。それより前に作成されたテーブルは残り、それ以降はスキップされます。

**KMIP キーリングコンポーネント** `component_keyring_file`、`component_keyring_kms`、`component_keyring_vault` はすべて同梱され、インストールできます。`component_keyring_kmip` はビルドされないため、インストールは `ERROR 1126` で失敗します。

**Percona の coredumper** `--coredumper` オプションは引き続き受け付けられます。サーバーは、ライブラリがビルドされているかどうかに関係なく、このオプションを登録するためです。ただし、ここではライブラリはビルドされていません。

Percona のその他の追加機能は通常どおり動作します。これには `percona_udf` コンポーネント、監査ログプラグイン、`USER_STATISTICS` ビューおよび `TABLE_STATISTICS` ビューが含まれます。

## Percona ビルドの識別 {#identifying-a-percona-build}

Percona ビルドは、バージョン文字列で異なるコードベースを報告します。

```sql
SELECT @@villagesql_server_version;
-- Example output: percona-8.4_0.0.6
```

この変数の意味については、[システムリファレンス](/ja/mysql-8.4/stable/reference#villagesql_server_version)を参照してください。VillageSQL は、あるコードベース (たとえば `mysql-8.4`) の datadir を、別のコードベース (たとえば `percona-8.4`) で実行中のサーバーへアップグレードすることを拒否します。

## インストール {#installing}

Percona ビルドは MySQL 8.4 ビルドと並行して提供され、3 つのインストール方法すべてで選べます。

**インストールスクリプト** 最初の質問で **Percona 8.4** を選びます。端末がない場合は、環境変数で直接指定します。

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=percona-8.4 INSTALL_METHOD=prebuilt bash
```

**Docker** イメージはコードベースごと、アーキテクチャごとに公開されています。

```bash
docker run -d --name vsql -e MYSQL_ALLOW_EMPTY_PASSWORD=yes -p 3306:3306 villagesql/server:percona-8.4_latest
```

**リリースのダウンロード** [0.0.6 リリース](https://github.com/villagesql/villagesql-server/releases/tag/release/0.0.6) にある `villagesql-dev-server-percona-8.4_0.0.6-<os>-<arch>.tar.gz` は、Linux の x86_64 と aarch64、および macOS の arm64 に対応します。

**ソース** `percona-8.4` ブランチをビルドします。リリースが提供したコードそのものをビルドするには `publish/percona-8.4_0.0.6` タグを使います。ビルド手順そのものは[ソースコードからのビルド](/ja/mysql-8.4/stable/source)を参照してください。

datadir は、それを作成したコードベースに属します。VillageSQL は `mysql-8.4` の datadir を `percona-8.4` のサーバーで開くことを拒否するため、このビルドは既存のディレクトリを指すのではなく、専用のディレクトリにインストールしてください。

Percona ビルドは MySQL 8.4 ビルドと並行して提供されます。インストールスクリプト、Docker、またはソースビルドでインストールします。

**インストールスクリプト (端末がある場合)。** スクリプトを実行し、最初の質問で **2) Percona 8.4** を選びます。

```bash
curl -fsSL https://install.villagesql.com | bash
```

**インストールスクリプト (端末がない場合)。** CI ジョブ、Dockerfile、AI エージェントなどでは、パイプの `bash` 側でコードベースとインストール方法を指定します。

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=percona-8.4 INSTALL_METHOD=prebuilt bash
```

**Docker。** イメージはコードベースごと、アーキテクチャごとに公開されています。

```bash
docker run -d --name vsql -e MYSQL_ROOT_PASSWORD=<your-password> -p 3306:3306 villagesql/server:percona-8.4_latest
```

**ソース。** [ソースコードからのビルド](/ja/mysql-8.4/stable/source-percona)に従ってください。

datadir は、それを作成したコードベースに属します。VillageSQL は `mysql-8.4` の datadir を `percona-8.4` のサーバーで開くことを拒否するため、このビルドは既存のディレクトリを指すのではなく、専用のディレクトリにインストールしてください。

MySQL には多くの領域があります。これらのガイドは、最もよく出てくる部分に焦点を当てています。最初のマイグレーションの前に一度だけ下す決定から、毎週手に取るテクニックまでです。どれも実践的で、VillageSQL で動作します。

SQL は初めてですか? [MySQL チュートリアル](/ja/tutorial/index)は、1 つのサンプルデータベースに対して、1 レッスンずつ順番に教えます。すでに SQL を書いているなら、[データ型の選択](/ja/guides/choosing-data-types)、[JOIN](/ja/guides/joins)、[インデックス](/ja/guides/mysql-indexes)から始めてください。他のすべてがその上に成り立つ基礎を扱っています。

VillageSQL 拡張機能は、`villagesql` クレートを使って Rust で書けます。SDK がすべての FFI マーシャリングを処理します。あなたは通常の Rust を書き、`extension!` マクロが、サーバーがロード時に呼び出す C のエントリポイントを生成します。

## Rust を選ぶべき場面 {#when-to-choose-rust}

次の場合、Rust が正しい選択です。

- Rust を好み、C++ のコードベースを必要としない
- ガベージコレクタなしでメモリ安全性が欲しい
- 新しい拡張機能を構築しており、既存の C++ 依存関係がない

既存の C++ コードベースがある場合、または現時点で最も完全なカスタム型ビルダー API が必要な場合は、[C++ 拡張機能の作成](/ja/guides/cpp-extensions)を参照してください。

<Warning>
API は拡張機能の開発に対して安定していますが、カスタム型ビルダー API はまだ成熟途上です。
</Warning>

## 前提条件 {#prerequisites}

必要なものは次のとおりです。

- **Rust の stable ツールチェーン** — [rustup.rs](https://rustup.rs) からインストール
- **cargo-vsql** — パッケージング、インストール、およびテストのための Cargo サブコマンド

SDK リポジトリから `cargo-vsql` をインストールします。

```bash
git clone https://github.com/villagesql/vsql-rust-sdk
cd vsql-rust-sdk
cargo install --path cargo-vsql
```

## 新しいクレートのセットアップ {#set-up-a-new-crate}

ライブラリクレートを作成し、SDK を追加して、設定します。

```bash
cargo new --lib vsql_my_extension
cd vsql_my_extension
cargo add villagesql
```

次に `Cargo.toml` でクレートの種類を設定します。

```toml
[lib]
crate-type = ["cdylib"]
```

`Cargo.toml` と同じ場所に `manifest.json` を追加します。

```json
{
  "name": "vsql_my_extension",
  "version": "0.1.0",
  "description": "My VillageSQL extension",
  "author": "Your Name",
  "license": "GPL-2.0"
}
```

## 関数を書く {#write-a-function}

[Rust での拡張機能の構築](/ja/extensions/build/rust-sdk)のページに、ROT-13 の例を使った完全な手順があります。要点は次のとおりです。`fn(&[InValue]) -> VdfReturn` を実装し、`func!` で登録し、全体を `extension!` で包みます。

```rust
use villagesql::{InValue, VdfReturn};

fn my_func_impl(args: &[InValue]) -> VdfReturn {
    match args.first() {
        Some(InValue::String(s)) => VdfReturn::string(s.to_uppercase()),
        Some(InValue::Null) | None => VdfReturn::null(),
        _ => VdfReturn::error("my_func: expected a STRING argument"),
    }
}

villagesql::extension! {
    funcs: [
        villagesql::func!(my_func_impl, "my_func", [villagesql::Type::String] -> villagesql::Type::String),
    ]
}
```

カスタム型（バイナリ格納、順序付け、ハッシュ化）については、[Rust のカスタム型](/ja/sdk/rust/custom-types)を参照してください。

## 拡張機能のテスト {#test-your-extension}

`mysql-test/t/basic.test` にテストを書きます。

```sql
INSTALL EXTENSION vsql_my_extension;
SELECT my_func('hello');
SELECT my_func(NULL);
UNINSTALL EXTENSION vsql_my_extension;
```

VillageSQL のビルドディレクトリを設定し、期待される結果を生成してから、実行します。

```bash
export VillageSQL_BUILD_DIR=/path/to/villagesql/build
cargo vsql test --record
cargo vsql test
```

成功した実行は、テストファイルごとに `[ pass ]` を出力します。

## SQL でのインストール {#install-in-sql}

パッケージングしてインストールします。

```bash
cargo vsql install
```

次に SQL で実行します。

```sql
INSTALL EXTENSION vsql_my_extension;
SELECT * FROM INFORMATION_SCHEMA.EXTENSIONS WHERE EXTENSION_NAME = 'vsql_my_extension';
SELECT my_func('hello');
-- → HELLO
```

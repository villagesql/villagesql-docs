## VillageSQL Server とは {#what-is-villagesql-server}

VillageSQL Server は、エージェント型 AI 時代に向けた拡張機能を備えた、MySQL のドロップイン代替です。その拡張フレームワークを使用すると、誰でも許可を求めることなく、またサーバーのコードを変更することなく、カスタムデータ型とカスタム関数をサーバーに追加できます。

## MySQL のための拡張機能 {#extensions-for-mysql}
拡張機能は、稼働中の VillageSQL サーバーに機能を追加します。拡張機能が追加できるものは次のとおりです。
- **カスタムデータ型:** `UUID`、`COMPLEX`、`INET` などの InnoDB カラム用の新しい型で、組み込み型と同じように使用できます。
- **カスタム関数:** C++ または Rust で書かれた、SQL から呼び出せる関数です。

拡張機能の追加と削除は SQL で行います: `INSTALL EXTENSION` と `UNINSTALL EXTENSION` です。

インストールできる拡張機能については、[拡張機能カタログ](/ja/extensions/catalog)を参照してください。

### 拡張機能の作成 {#build-an-extension}
[拡張機能テンプレート](https://github.com/villagesql/vsql-extension-template)から始めて、[C++ ガイド](/guides/cpp-extensions)または [Rust ガイド](/guides/rust-extensions)に従ってください。AI の支援を受けたガイド付きワークフローを試すには、[Extension Builder](https://villagesql.com/agent-skills) をお試しください。

## VillageSQL を選ぶ理由 {#why-villagesql}

<CardGroup cols={2}>
  <Card title="ドロップイン互換性" icon="check-double">
    VillageSQL は MySQL プロトコルを話すため、お使いの MySQL クライアントとドライバーがそのまま接続できます。
  </Card>
  <Card title="拡張可能なコア" icon="puzzle-piece">
    `INSTALL EXTENSION` で稼働中のサーバーに機能を追加します。サーバーの再起動は必要ありません。
  </Card>
  <Card title="オープンなエコシステム" icon="users">
    誰でも拡張機能を作成できます。カタログには、コミュニティが作成した拡張機能が VillageSQL が作成した拡張機能と並んで掲載されています。
  </Card>
  <Card title="使い慣れたツール" icon="wrench">
    `mysqld` や `mysql` クライアントなど、すでに知っている MySQL のツールと設定ファイルをそのまま使用できます。
  </Card>
</CardGroup>

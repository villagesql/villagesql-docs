Sakila は 1 つの zip に入った 2 つの SQL ファイルとして届きます。1 つ目が
テーブルを作り、2 つ目がそれらを埋めます。[サーバーのインストール](/ja/tutorial/install-mysql)の
サーバーに対して、その順序で実行します。

## ダウンロードする {#download-it}

好きなディレクトリでこれらを実行してください。

```bash
curl -O https://downloads.mysql.com/docs/sakila-db.zip
unzip sakila-db.zip
```

これで `sakila-db` ディレクトリができます。その中から必要な 2 つのファイルは
`sakila-schema.sql` と `sakila-data.sql` です。

## ロードする {#load-it}

スキーマファイルが先、データファイルが後です。`root` にパスワードがなければ、
各パスワードプロンプトで Return を押してください。

```bash
mysql -u root -p < sakila-db/sakila-schema.sql
mysql -u root -p < sakila-db/sakila-data.sql
```

どちらのコマンドも、成功したときはパスワードプロンプトの後に何も表示
しません。データファイルのほうが時間がかかります。データベースのすべての行を
挿入するからです。

<Note>
スキーマファイルが最初に行うのは `DROP SCHEMA IF EXISTS sakila` です。この
2 つのコマンドをもう一度実行するとデータベースが一から作り直されるので、
いつでもきれいなコピーに戻れます。変更した内容はすべて失われます。
</Note>

## 確認する {#check-it}

データベースに今何が入っているかをサーバーに尋ねます。

```bash
mysql -u root -p -e "USE sakila; SHOW TABLES;"
```

```text

| staff_list                 |

```

23 個の名前があります。`SHOW TABLES` は 16 個のテーブルと 7 個のビューを
まとめて列挙するからです。

テーブルがデータなしで届くこともあるので、何かを数えてもみてください。

```bash
mysql -u root -p -e "SELECT COUNT(*) FROM sakila.film;"
```

```text
Enter password:
+----------+
| COUNT(*) |
+----------+
|     1000 |
+----------+
```

1,000 本の映画があれば、最初のレッスンの準備は整っています。

## データベースの中で作業する {#work-inside-the-database}

すべてのレッスンは、`sakila` が現在のデータベースであるものとしてクエリを
書いています。クライアントを開くときに名前を指定してください。

```bash
mysql -u root -p sakila
```

または、中に入ってから切り替えます。

```sql
USE sakila;
```

このどちらかをしないと、`film` を参照するクエリは失敗します。

```bash
mysql -u root -p -e "SELECT COUNT(*) FROM film;"
```

```text
Enter password:
ERROR 1046 (3D000) at line 1: No database selected
```

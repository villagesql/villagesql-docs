このチュートリアルは、MySQL 上の SQL を順番に、1 レッスンずつ教えます。すべての
レッスンは同じサンプルデータベースに問い合わせるため、各レッスンは新しい
テーブルを作り出すのではなく、既にロードしたデータの上に積み上がります。表示
されるすべての結果は、動作中のサーバーから取得した出力なので、自分の画面を
ページと照らし合わせて確認できます。

SQL が初めてなら、順番に読んでください。既に SQL を書いていて、1 つの質問に
対する 1 つの答えが欲しいなら、MySQL ガイドが同じ内容をレッスン別ではなく
タスク別に整理して扱っています。

## VillageSQL の位置づけ {#where-villagesql-fits}

VillageSQL は拡張機能フレームワークを追加した MySQL なので、このチュートリアルの
すべての文はそのまま VillageSQL 上で動作します。ここにあるレッスンで拡張機能を
必要とするものはありません。終えたあとは、拡張機能がその上に追加するものを
ガイドが扱います。

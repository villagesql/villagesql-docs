Percona 构建与 MySQL 8.4 构建一同发布。您可以使用安装脚本、Docker
或源码构建来安装它。

**安装脚本（在终端中）。** 运行脚本，然后在第一个问题中选择 **2) Percona 8.4**：

```bash
curl -fsSL https://install.villagesql.com | bash
```

**安装脚本（没有终端）。** 在 CI 任务、带有非 root `USER` 的 Dockerfile 或 AI 智能体中，
请在管道的 `bash` 一侧指定代码库和安装方式：

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=percona-8.4 INSTALL_METHOD=prebuilt bash
```

**Docker。** 镜像按代码库和架构分别发布：

```bash
docker run -d --name vsql -e MYSQL_ROOT_PASSWORD=<your-password> -p 3306:3306 villagesql/server:percona-8.4_latest
```

**源码。** 请按照[从源代码构建](/zh/8.4/stable/source-percona)进行操作。

数据目录属于创建它的代码库。VillageSQL 拒绝用 `percona-8.4` 服务器打开
`mysql-8.4` 的数据目录，因此请将此构建安装到独立目录，而不要指向已有目录。

## 后续步骤

要连接到服务器并安装您的第一个扩展，请从步骤 2 开始按照[安装](/zh/8.4/stable/install-server#step-2-connect-to-the-server)进行操作。这些步骤在 Percona 构建上完全相同。

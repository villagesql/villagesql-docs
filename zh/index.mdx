## 什么是 VillageSQL Server？

VillageSQL Server 是 MySQL 的直接替代品，并带有面向智能体 AI 时代的扩展。它的扩展框架让任何人都可以为服务器添加自定义数据类型和自定义函数，无需征得许可，也无需修改服务器代码。

## MySQL 的扩展
扩展为正在运行的 VillageSQL 服务器添加功能。扩展可以添加：
- **自定义数据类型：** 用于 InnoDB 列的新类型，例如 `UUID`、`COMPLEX` 和 `INET`，用法与内置类型相同。
- **自定义函数：** 用 C++ 或 Rust 编写、可从 SQL 调用的函数。

您用 SQL 添加和移除扩展：`INSTALL EXTENSION` 和 `UNINSTALL EXTENSION`。

可安装的扩展请参阅[扩展目录](/zh/extensions/catalog)。

### 构建扩展
从[扩展模板](https://github.com/villagesql/vsql-extension-template)开始，并按照 [C++ 指南](/guides/cpp-extensions)或 [Rust 指南](/guides/rust-extensions)进行操作。如需 AI 辅助的引导式工作流，请试用[扩展构建器](https://villagesql.com/agent-skills)。

## 使用安装脚本安装 {#install-with-the-install-script}

```bash
curl -fsSL https://install.villagesql.com | bash
```

脚本会询问安装哪个代码库（MySQL 8.4、Percona Server 8.4 或 MySQL 9.7）以及用哪种方式安装：预编译下载、Docker 或源码构建。预编译安装会放在 `~/.villagesql/` 下，并在端口 3306 上启动服务器。请以普通用户身份运行它：以 root 身份运行时，它会退出并显示 `Error: Running this installer as root is not supported.`

如果没有终端来回答这些问题（CI 任务、带有非 root `USER` 的 Dockerfile、AI 智能体），请用环境变量传入答案，并设置在管道的 `bash` 一侧：

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=mysql-8.4 INSTALL_METHOD=prebuilt bash
```

`VSQL_CODEBASE` 接受 `mysql-8.4`、`percona-8.4` 或 `mysql-9.7`。`INSTALL_METHOD` 接受 `docker`、`prebuilt` 或 `source`。源码构建还需要 `VSQL_VERSION=stable|nightly|latest`；Docker 和预编译安装始终使用稳定版本。

要连接服务器并安装您的第一个扩展，请参阅[安装](/zh/8.4/stable/install-server#step-2-connect-to-the-server)。

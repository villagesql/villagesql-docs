## 使用安装脚本安装 {#install-with-the-install-script}

```bash
curl -fsSL https://install.villagesql.com | bash
```

脚本会询问安装哪个代码库（MySQL 8.4、Percona Server 8.4 或 MySQL 9.7）以及用哪种方式安装：预编译下载、Docker 或源码构建。预编译安装会放在 `~/.villagesql/` 下，并在端口 3306 上启动服务器。

要连接服务器并安装您的第一个扩展，请参阅[安装](/zh/8.4/stable/install-server#step-2-connect-to-the-server)。

子查询是嵌在另一个查询里的查询。它让您使用一个您还不知道的答案：最长的影片、平均评分、匹配某个条件的一组 id。没有它，您就得运行 2 个查询，再把第一个结果手动粘贴进第二个。

开始之前，请用 `mysql -u root -p sakila` 打开客户端。

## 子查询的工作原理 {#how-a-subquery-works}

```sql
SELECT COLUMN_LIST
FROM TABLE_NAME
WHERE COLUMN_NAME = (SELECT AGGREGATE_FUNCTION(COLUMN_NAME) FROM TABLE_NAME);
```

把 `COLUMN_LIST` 替换为您想要的列，`TABLE_NAME` 替换为表，`COLUMN_NAME` 替换为要测试的列，`AGGREGATE_FUNCTION` 替换为生成您要比较的值的函数。

服务器运行子查询，取它的结果，并在外层查询中使用它。

括号中恰好返回 1 行 1 列的子查询是标量子查询，它的行为像一个值。这就是下面的形式，也是最常出错的形式。

## 示例 {#examples}

### 1) 使用一个您写不出来的值 {#1-use-a-value-you-cannot-write-down}

您不知道最长影片的时长，所以就地把它要过来。

```sql
SELECT title, length
FROM film
WHERE length = (SELECT MAX(length) FROM film)
ORDER BY title;
```

```text
+--------------------+--------+
| title              | length |
+--------------------+--------+
| CHICAGO NORTH      |    185 |
| CONTROL ANTHEM     |    185 |
| DARN FORRESTER     |    185 |
...
+--------------------+--------+
10 rows in set (0.00 sec)
```

`MAX(length)` 单独使用只会给出 185，别的什么都没有。子查询把它送回一个 `WHERE` 中，这样您也能得到那些影片。

### 2) 选择列表中的子查询 {#2-a-subquery-in-the-select-list}

同一个值可以放进选择列表，它会在每一行上重复。

```sql
SELECT title, length, (SELECT AVG(length) FROM film) AS catalog_mean
FROM film
ORDER BY title
LIMIT 3;
```

```text
+------------------+--------+--------------+
| title            | length | catalog_mean |
+------------------+--------+--------------+
| ACADEMY DINOSAUR |     86 |     115.2720 |
| ACE GOLDFINGER   |     48 |     115.2720 |
| ADAPTATION HOLES |     50 |     115.2720 |
+------------------+--------+--------------+
3 rows in set (0.00 sec)
```

子查询只运行一次，它的答案沿着这一列复制下来，这就是把一个值显示在要与它比较的那些行旁边的方法。

### 3) 返回列表的子查询 {#3-a-subquery-that-returns-a-list}

供给 [IN](/zh/tutorial/in) 的子查询允许返回多行，因为 `IN` 期望的是一个列表而不是一个值。

```sql
SELECT first_name, last_name
FROM actor
WHERE actor_id IN (SELECT actor_id FROM film_actor WHERE film_id = 1)
ORDER BY last_name
LIMIT 5;
```

```text
+------------+-----------+
| first_name | last_name |
+------------+-----------+
| JOHNNY     | CAGE      |
| ROCK       | DUKAKIS   |
| CHRISTIAN  | GABLE     |
| PENELOPE   | GUINESS   |
| MARY       | KEITEL    |
+------------+-----------+
5 rows in set (0.00 sec)
```

内层查询返回影片 1 中所有人的 id，`IN` 把每位演员与整个列表比对。

## ERROR 1242 表示子查询返回了太多行 {#error-1242-means-the-subquery-returned-too-many-rows}

`=` 把 1 个东西与 1 个东西比较。给它一个返回 1,000 行的子查询，服务器就无法继续。

```sql
SELECT title FROM film WHERE length = (SELECT length FROM film);
```

```text
ERROR 1242 (21000): Subquery returns more than 1 row
```

有 3 条出路，取决于您的本意：

- 当您想要的是一个列表时，用 `IN` 代替 `=`。
- 当您想从集合中得到 1 个值时，加一个聚合函数，如 `MAX()`。
- 当任意 1 行都可以、而且您能用 `ORDER BY` 说明是哪一行时，加 `LIMIT 1`。

`ERROR 1242` 至少失败得很响亮。这个错误的另一个版本则不会：子查询根本不返回任何行，于是得到 NULL，比较得到 NULL，外层查询悄无声息地什么都不返回。

## 总结 {#summary}

- 用子查询把一个查询的答案送进另一个查询。
- 预期标量子查询，即 1 行 1 列，表现得像一个值。
- 把 `ERROR 1242` 理解为 `=` 遇到了返回多行的子查询。
- 当子查询返回列表时，用 `IN` 而不是 `=`。
- 当外层查询什么都不返回又没有错误时，怀疑子查询为空。

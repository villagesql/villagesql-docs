本教程按顺序、一次一课地教您在 MySQL 上使用 SQL。每一课都查询同一个示例数据库，所以每一课都建立在您已经加载的数据之上，而不是另造新表。显示的每个结果都是从运行中的服务器捕获的输出，所以您可以把屏幕与页面对照。

如果您是 SQL 新手，请按顺序阅读。如果您已经会写 SQL，只想为一个问题找到一个答案，MySQL 指南覆盖了同样的内容，但按任务而不是按课程组织。

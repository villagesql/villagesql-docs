连接把表并排放置，让结果变宽。`UNION` 把结果上下叠放，让结果变长。当 2 个查询产生相同形状的行，而您想把它们放进 1 个列表时，就用它。

开始之前，请用 `mysql -u root -p sakila` 打开客户端。

## UNION 的工作原理 {#how-union-works}

```sql
SELECT COLUMN_LIST FROM FIRST_TABLE
UNION
SELECT COLUMN_LIST FROM SECOND_TABLE;
```

把每个 `COLUMN_LIST` 替换为您想要的列，`FIRST_TABLE` 和 `SECOND_TABLE` 替换为要读取的表。

2 个查询必须返回相同数量的列，服务器按位置而不是按名字匹配这些列。

`UNION` 去除重复行。`UNION ALL` 保留它们，而且更快，因为它不必比较任何东西。

## 示例 {#examples}

### 1) UNION 去除重复 {#1-union-removes-duplicates}

这里的两部分是同一个查询，所以第二部分的每一行都是第一部分某一行的重复。

```sql
SELECT rating FROM film UNION SELECT rating FROM film;
```

```text
+--------+
| rating |
+--------+
| PG     |
| G      |
| NC-17  |
| PG-13  |
| R      |
+--------+
5 rows in set (0.00 sec)
```

从 2,000 行得到 5 行。`UNION` 一次性对合并后的结果去重，所以一部分内部的重复与两部分之间的重复处理方式相同。答案与同一列上的 [SELECT DISTINCT](/zh/tutorial/select-distinct) 一致。

### 2) UNION ALL 保留它们 {#2-union-all-keeps-them}

```sql
SELECT rating FROM film UNION ALL SELECT rating FROM film;
```

```text
+--------+
| rating |
+--------+
| PG     |
| G      |
| NC-17  |
...
+--------+
2000 rows in set (0.00 sec)
```

两部分的每一行。当您知道没有重复，或者重复正是目的时，就用 `UNION ALL`。

### 3) 叠放来自不同表的行 {#3-stack-rows-from-different-tables}

这才是 `UNION` 真正的用途：2 个保存同类事物的表。一个字面值列说明每一行来自哪一部分。

```sql
SELECT 'staff' AS source, first_name, last_name FROM staff
UNION ALL
SELECT 'actor', first_name, last_name FROM actor WHERE actor_id <= 3;
```

```text
+--------+------------+-----------+
| source | first_name | last_name |
+--------+------------+-----------+
| staff  | Mike       | Hillyer   |
| staff  | Jon        | Stephens  |
| actor  | PENELOPE   | GUINESS   |
| actor  | NICK       | WAHLBERG  |
| actor  | ED         | CHASE     |
+--------+------------+-----------+
5 rows in set (0.00 sec)
```

第二个查询没有给它的字面值起别名。它不需要，因为列标题只来自第一个查询。

## UNION 不保证顺序 {#union-does-not-promise-an-order}

任何一部分都不保证整块连续到达，也不保证先到达。服务器按其计划产生行的顺序返回它们，所以 2 个相同查询的 `UNION ALL` 可能会交错。末尾的 `ORDER BY` 是唯一能固定顺序的方法，这与 [LIMIT](/zh/tutorial/limit) 和 [GROUP BY](/zh/tutorial/group-by) 的情况相同。

## 两部分的列数必须相同 {#the-halves-must-have-the-same-number-of-columns}

```sql
SELECT first_name FROM actor UNION SELECT first_name, last_name FROM actor;
```

```text
ERROR 1222 (21000): The used SELECT statements have a different number of columns
```

列名不必匹配。数量是严格的，而且在任何东西运行之前就会检查。

## ORDER BY 作用于整个结果 {#order-by-applies-to-the-whole-result}

末尾的 `ORDER BY` 对合并后的行排序，而不是对最后一个查询排序。请写第一部分的别名，那就是结果列的名字。

```sql
SELECT first_name AS name FROM staff
UNION
SELECT last_name FROM staff
ORDER BY name;
```

```text
+----------+
| name     |
+----------+
| Hillyer  |
| Jon      |
| Mike     |
| Stephens |
+----------+
4 rows in set (0.00 sec)
```

要单独对 1 部分排序或限制行数，请把那一部分用括号括起来，并把它的 `ORDER BY` 和 `LIMIT` 放在括号里面。

## 总结 {#summary}

- 用 `UNION` 把 2 个查询的行叠成 1 个结果。
- 预期 `UNION` 去除重复，`UNION ALL` 保留重复。
- 当您知道没有重复时，优先用 `UNION ALL`，因为它做的工作更少。
- 给两部分相同数量的列，否则得到 `ERROR 1222`。
- 预期列标题来自第一个查询，末尾的 `ORDER BY` 对整个结果排序。

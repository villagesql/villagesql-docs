`SELECT` 从表中读出行。这一课介绍它最小的有用形式：指定一个表，指定一些列，取回行。

每个示例都查询 Sakila 数据库。如果您还没有加载它，请[先加载 Sakila](/zh/tutorial/load-sakila)，然后用 `mysql -u root -p sakila` 打开客户端，让 `sakila` 成为当前数据库。

## SELECT 的工作原理 {#how-select-works}

```sql
SELECT COLUMN_LIST
FROM TABLE_NAME;
```

`COLUMN_LIST` 是您想在每一行中得到的东西，通常是用逗号分隔的列名。`TABLE_NAME` 是行所来自的表。

语句在分号处结束。客户端会一直读到找到分号为止，所以没有分号的一行会让您停在续行提示符上：

```text
mysql> SELECT name FROM language
    -> ;
+----------+
| name     |
+----------+
| English  |
| Italian  |
| Japanese |
| Mandarin |
| French   |
| German   |
+----------+
6 rows in set (0.00 sec)
```

## 示例 {#examples}

### 1) 选取一列 {#1-select-one-column}

向 `film` 表要每部影片的标题，别的什么都不要。

```sql
SELECT title FROM film;
```

```text
+-----------------------------+
| title                       |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
| AFFAIR PREJUDICE            |
| AFRICAN EGG                 |
...
+-----------------------------+
1000 rows in set (0.01 sec)
```

表中每一行都返回一行，这里是 1,000 行。`SELECT` 自己不做任何筛选。决定您得到哪些行是 [WHERE](/zh/tutorial/where) 的工作。

### 2) 选取几列 {#2-select-several-columns}

用逗号分隔列名。它们按您要求的顺序返回，这个顺序不必是它们在表中的顺序。

```sql
SELECT title, release_year, rental_rate FROM film;
```

```text
+-----------------------------+--------------+-------------+
| title                       | release_year | rental_rate |
+-----------------------------+--------------+-------------+
| ACADEMY DINOSAUR            |         2006 |        0.99 |
| ACE GOLDFINGER              |         2006 |        4.99 |
| ADAPTATION HOLES            |         2006 |        2.99 |
| AFFAIR PREJUDICE            |         2006 |        2.99 |
| AFRICAN EGG                 |         2006 |        2.99 |
...
+-----------------------------+--------------+-------------+
1000 rows in set (0.00 sec)
```

### 3) 选取每一列 {#3-select-every-column}

星号代表表中的每一列。`language` 表有 6 行，所以这个查询打印出完整的结果。

```sql
SELECT * FROM language;
```

```text
+-------------+----------+---------------------+
| language_id | name     | last_update         |
+-------------+----------+---------------------+
|           1 | English  | 2006-02-15 05:02:19 |
|           2 | Italian  | 2006-02-15 05:02:19 |
|           3 | Japanese | 2006-02-15 05:02:19 |
|           4 | Mandarin | 2006-02-15 05:02:19 |
|           5 | French   | 2006-02-15 05:02:19 |
|           6 | German   | 2006-02-15 05:02:19 |
+-------------+----------+---------------------+
6 rows in set (0.00 sec)
```

`SELECT *` 在您探索一个不了解的表时有它的用处。在应用程序代码里，请写出列名。星号会把每一列都通过网络发送出去，无论代码读不读它，而且在有人添加一列的那天，它会在代码底下悄悄改变形状。

### 4) 计算一个值 {#4-compute-a-value}

选择列表不一定要写列名。在那里放一个表达式，结果就成为一个独立的列。

```sql
SELECT title, rental_rate, rental_rate * 1.1 FROM film;
```

```text
+-----------------------------+-------------+-------------------+
| title                       | rental_rate | rental_rate * 1.1 |
+-----------------------------+-------------+-------------------+
| ACADEMY DINOSAUR            |        0.99 |             1.089 |
| ACE GOLDFINGER              |        4.99 |             5.489 |
| ADAPTATION HOLES            |        2.99 |             3.289 |
| AFFAIR PREJUDICE            |        2.99 |             3.289 |
| AFRICAN EGG                 |        2.99 |             3.289 |
...
+-----------------------------+-------------+-------------------+
1000 rows in set (0.00 sec)
```

第三列的标题就是您输入的表达式，准确但难看。[列别名](/zh/tutorial/column-aliases)可以给它一个您自己起的名字。

## 2 件让人出错的事 {#2-things-that-catch-people-out}

**关键字不区分大小写。** `SELECT`、`select` 和 `SeLeCt` 都能运行。

```sql
select title from film;
```

```text
+-----------------------------+
| title                       |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
...
+-----------------------------+
1000 rows in set (0.00 sec)
```

本教程按惯例把关键字写成大写，其他一切写成小写。这个惯例的目的是让长查询的结构一眼就能看出来。

**拼错的列名会引发错误。** MySQL 不会猜您的意思，也不会返回一个空结果。

```sql
SELECT titel FROM film;
```

```text
ERROR 1054 (42S22): Unknown column 'titel' in 'field list'
```

`field list` 是服务器对选择列表的称呼，所以这条消息既指出了错误，也定位了它。当错误的名字位于语句的其他位置时，同一个错误的结尾会不同，所以在去查找之前先读一读它的结尾。

## 总结 {#summary}

- 用 `SELECT` 加一个列的列表、`FROM` 加一个表来读取行。
- 按您希望返回的任何顺序列出列。
- 探索时使用 `SELECT *`，在应用程序代码中写出列名。
- 在选择列表中放一个表达式，为每一行计算一个值。
- 当列名有误时，预期 `ERROR 1054`。

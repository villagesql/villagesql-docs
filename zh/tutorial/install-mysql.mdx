您需要一个运行中的服务器，以及一个能与它通信的客户端。任何 MySQL 8.4 或更高版本的服务器都可以，VillageSQL 也可以，它是加上了扩展框架的 MySQL。这里没有任何一课使用扩展，所以两者都行。

## 选择一种运行服务器的方式 {#pick-a-way-to-run-a-server}

| 方式 | 适合 | 去哪里 |
|---|---|---|
| Docker | 试一试然后丢掉 | [Docker 上的 MySQL](/zh/guides/mysql-on-docker) |
| VillageSQL 安装程序 | 保留在您自己机器上的服务器 | [安装](/zh/8.4/stable/install-server) |
| 您已经在运行的服务器 | 任何已安装 MySQL 8.4 或更高版本的人 | 无需操作 |

这些页面每一个都以一个运行中的服务器结束。有了之后，请回到这里。

## 获取客户端 {#get-a-client}

本教程用命令行客户端 `mysql` 驱动服务器。它从哪里来，取决于您选的方式：

- **安装程序。** 安装程序把客户端放在 `~/.villagesql/` 中，但不在您的 `PATH` 上。运行保存在 `~/.villagesql/credentials.txt` 中的 `Connect` 命令（root 密码在同一个文件里），然后在 `mysql>` 提示符下运行 `SELECT VERSION();`，以代替下面的命令。
- **已有的服务器。** 客户端随服务器一起安装，所以您已经有了。
- **Docker。** 客户端在容器内部，不在您的机器上。用 `docker exec -it CONTAINER_NAME mysql -u root -p` 访问它，或者在本地安装一个客户端，通过容器发布的端口连接。

## 检查您能否连接 {#check-that-you-can-connect}

运行这条命令；如果 `root` 没有密码，在密码提示处按回车：

```bash
mysql -u root -p -e "SELECT VERSION();"
```

```text
Enter password:
+-----------------------------------------+
| VERSION()                               |
+-----------------------------------------+
| 8.4.11-villagesql-0.0.7-dev-c857bdf32ce |
+-----------------------------------------+
```

您的版本字符串会不同。重要的是返回了一个版本，因为这表示客户端到达了服务器并登录成功。

## 连接不上时 {#when-it-does-not-connect}

下面 2 个错误都表示客户端从未到达任何服务器，所以都与您的密码无关。在正常工作的环境上，把客户端指向错误的地方，就能重现其中任何一个。

套接字路径背后什么都没有：

```bash
mysql -S /tmp/mysql.sock.missing -u root -p -e "SELECT VERSION();"
```

```text
Enter password:
ERROR 2002 (HY000): Can't connect to local MySQL server through socket '/tmp/mysql.sock.missing' (2)
```

端口上没有任何东西在监听：

```bash
mysql -h 127.0.0.1 -P 3999 -u root -p -e "SELECT VERSION();"
```

```text
Enter password:
ERROR 2003 (HY000): Can't connect to MySQL server on '127.0.0.1:3999' (61)
```

末尾括号中的数字是操作系统自己的错误号，所以在 macOS 和 Linux 之间可能不同。套接字缺失的错误号在两者上都是 2；连接被拒绝的错误号在 macOS 上是 61，在 Linux 上是 111。要读的部分是套接字路径或者主机和端口，因为它告诉您客户端去哪里找了。如果那个位置错了，就改正它。如果它是对的，那就是服务器没有运行。

`=` 把一个值与 1 个值比较。`ANY` 和 `ALL` 把一个比较放在整个子查询结果的前面：大于其中任意一个，大于其中所有。您在别人的查询中遇到它们的次数会多于自己写它们的次数，所以这一课要学到的，是能够读懂它们。

开始之前，请用 `mysql -u root -p sakila` 打开客户端。

## ANY 和 ALL 的工作原理 {#how-any-and-all-work}

```sql
SELECT COLUMN_LIST
FROM TABLE_NAME
WHERE COLUMN_NAME > ALL (SELECT COLUMN_NAME FROM OTHER_TABLE);
```

把 `COLUMN_LIST` 换成您想要的列，把 `TABLE_NAME` 换成表，把 `COLUMN_NAME` 换成要测试的列，把 `OTHER_TABLE` 换成子查询读取的表。把 `>` 换成任何比较运算符。

当比较对至少 1 个返回行成立时，`ANY` 为真。当比较对每一行都成立时，`ALL` 为真。`SOME` 是 `ANY` 的另一种写法，意思完全相同。

当子查询中的 NULL 让答案无法确定时，两者都给出 NULL 而不是真或假，这与任何其他针对 NULL 的比较一样，然后 `WHERE` 会丢弃这一行。

请按照字面意思来读它们：`> ANY` 是"比它们之中至少一个大"，这等同于比最小的那个大。`> ALL` 是"比它们之中每一个都大"，等同于比最大的那个大。

## 示例 {#examples}

### 1) 比至少一个大 {#1-bigger-than-at-least-one}

```sql
SELECT title, length
FROM film
WHERE length > ANY (SELECT length FROM film WHERE rating = 'G')
ORDER BY length, title
LIMIT 3;
```

```text
+---------------------+--------+
| title               | length |
+---------------------+--------+
| ACE GOLDFINGER      |     48 |
| HEAVEN FREEDOM      |     48 |
| MIDSUMMER GROUNDHOG |     48 |
+---------------------+--------+
3 rows in set (0.00 sec)
```

最短的 `G` 电影时长 47 分钟，所以每部 48 分钟或更长的电影都符合条件。

### 2) 比每一个都大 {#2-bigger-than-every-one}

```sql
SELECT title, length
FROM film
WHERE length > ALL (SELECT length FROM film WHERE rating = 'G')
ORDER BY title;
```

```text
Empty set (0.01 sec)
```

没有行，而这是正确的答案。最长的 `G` 电影是 185 分钟，这也是整个目录中最长的电影，所以没有什么比它们全部都长。

### 3) = ANY 就是 IN {#3--any-is-in}

```sql
SELECT title FROM film WHERE rating = ANY (SELECT rating FROM film WHERE title = 'ACADEMY DINOSAUR') ORDER BY title LIMIT 3;
```

```text
+------------------+
| title            |
+------------------+
| ACADEMY DINOSAUR |
| AGENT TRUMAN     |
| ALASKA PHANTOM   |
+------------------+
3 rows in set (0.00 sec)
```

`= ANY` 和 [IN](/zh/tutorial/in) 是同一个运算符的 2 种写法，而 `IN` 是人们读得更快的那一种。同样，`<> ALL` 就是 `NOT IN`，带有那一课所描述的同一个 NULL 陷阱。

## 空子查询会让它们翻转 {#an-empty-subquery-flips-them}

这是值得了解的部分，因为它看起来是错的。

```sql
SELECT title, length
FROM film
WHERE length > ALL (SELECT length FROM film WHERE rating = 'X')
ORDER BY title
LIMIT 3;
```

```text
+------------------+--------+
| title            | length |
+------------------+--------+
| ACADEMY DINOSAUR |     86 |
| ACE GOLDFINGER   |     48 |
| ADAPTATION HOLES |     50 |
+------------------+--------+
3 rows in set (0.00 sec)
```

没有电影分级为 `X`，所以子查询什么都不返回，而每部电影都回来了。对空集合的 `ALL` 为真：没有任何一行不通过测试。出于相反的原因，对空集合的 `ANY` 为假，所以同一个查询改用 `ANY` 什么都不返回。

因此，子查询中的一个笔误会在 `ALL` 下给您整张表，在 `ANY` 下给您空结果，两种情况都不会报错。

## 总结 {#summary}

- 把 `> ANY` 读作比最小的大，把 `> ALL` 读作比最大的大。
- 把 `SOME` 读作 `ANY` 的另一种写法。
- 优先用 `IN` 而不是 `= ANY`，用 `NOT IN` 而不是 `<> ALL`，因为它们读得更快。
- 当子查询什么都不返回时，预期 `ALL` 为真而 `ANY` 为假。
- 当子查询中的 NULL 让结果无法确定时，预期得到 NULL 而不是真或假。

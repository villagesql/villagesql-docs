`RIGHT JOIN` 保留右侧表的每一行，无论是否匹配。它是 [LEFT JOIN](/zh/tutorial/left-join) 的镜像，`LEFT JOIN` 做不到的事它也做不到，所以这一课很短。这一课存在的原因是您会在别人的 SQL 中读到 `RIGHT JOIN`。

开始之前，请用 `mysql -u root -p sakila` 打开客户端。

## RIGHT JOIN 的工作原理 {#how-right-join-works}

```sql
SELECT COLUMN_LIST
FROM LEFT_TABLE
RIGHT JOIN RIGHT_TABLE ON LEFT_TABLE.COLUMN_NAME = RIGHT_TABLE.COLUMN_NAME;
```

把 `COLUMN_LIST` 替换为您想要的列，`LEFT_TABLE` 替换为您起始的表，`RIGHT_TABLE` 替换为您想保留其每一行的表，每个 `COLUMN_NAME` 替换为该侧用来关联两表的列。没有任何匹配的右侧行返回时，左表的每一列都为 NULL。`RIGHT OUTER JOIN` 是同一个子句的完整写法。

## 示例 {#examples}

### 1) 保留第二个表的每一行 {#1-keep-every-row-of-the-second-table}

`film` 在左，`language` 在右，所以这保留了全部 6 种语言。

```sql
SELECT l.name, f.title
FROM film AS f
RIGHT JOIN language AS l ON f.language_id = l.language_id
ORDER BY l.name, f.title;
```

```text
+----------+-----------------------------+
| name     | title                       |
+----------+-----------------------------+
| English  | ACADEMY DINOSAUR            |
| English  | ACE GOLDFINGER              |
| English  | ADAPTATION HOLES            |
...
+----------+-----------------------------+
1005 rows in set (0.00 sec)
```

1,005 行，与 `LEFT JOIN` 课程用同样 2 个表按相反顺序得到的行数相同。

### 2) 列出没有匹配到任何东西的行 {#2-list-the-rows-that-matched-nothing}

与左连接相同的模式，只是现在 NULL 测试放在左表上。

```sql
SELECT f.title, l.name
FROM film AS f
RIGHT JOIN language AS l ON f.language_id = l.language_id
WHERE f.film_id IS NULL
ORDER BY l.name;
```

```text
+-------+----------+
| title | name     |
+-------+----------+
| NULL  | French   |
| NULL  | German   |
| NULL  | Italian  |
| NULL  | Japanese |
| NULL  | Mandarin |
+-------+----------+
5 rows in set (0.00 sec)
```

没有任何影片使用的 5 种语言。

## 每个 RIGHT JOIN 都可以写成 LEFT JOIN {#every-right-join-can-be-written-as-a-left-join}

`a RIGHT JOIN b` 返回的行与 `b LEFT JOIN a` 相同。交换 2 个表名，交换关键字，答案不变。使用 `SELECT *` 时，列会以不同的顺序返回，因为 `*` 按表在 `FROM` 中出现的顺序展开，所以当顺序重要时请写出列名。

您读到的大多数 SQL 都因此用 `LEFT JOIN` 来写：当查询中的每个连接都朝向同一个方向时，查询更容易理解。

它的其他一切，包括 `WHERE` 陷阱，都与 [LEFT JOIN](/zh/tutorial/left-join) 课程描述的完全一样，只是左右互换。

## 总结 {#summary}

- 用 `RIGHT JOIN` 保留第二个写出的表的每一行。
- 对于没有匹配到任何东西的行，预期它的每个左侧列都是 NULL。
- 把 `a RIGHT JOIN b` 读作 `b LEFT JOIN a`，并写出列名而不是使用 `*`。
- 在您写的 SQL 中优先使用 `LEFT JOIN`，让查询中的连接都朝向同一个方向。

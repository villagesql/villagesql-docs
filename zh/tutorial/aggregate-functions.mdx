到目前为止，每个查询返回的都是行。聚合函数读取多行并返回 1 个值：有多少、总计、平均值、最大值。当问题针对的是一个集合而不是一行时，它是您最先要用到的东西。

开始之前，请用 `mysql -u root -p sakila` 打开客户端。

## 聚合函数的工作原理 {#how-an-aggregate-function-works}

```sql
SELECT AGGREGATE_FUNCTION(COLUMN_NAME)
FROM TABLE_NAME;
```

把 `AGGREGATE_FUNCTION` 换成下面的函数之一，把 `COLUMN_NAME` 换成要读取的列，把 `TABLE_NAME` 换成表。

| 函数 | 返回 |
|---|---|
| `COUNT(*)` | 有多少行，包括 NULL |
| `COUNT(column)` | 有多少行在该列中有值 |
| `SUM(column)` | 总计 |
| `AVG(column)` | 平均值 |
| `MIN(column)` | 最小值 |
| `MAX(column)` | 最大值 |

没有 `GROUP BY` 时，整个表是 1 个组，所以结果总是恰好 1 行。[GROUP BY](/zh/tutorial/group-by) 是改为每个类别得到 1 行的方法。

## 示例 {#examples}

### 1) 统计行数 {#1-count-the-rows}

```sql
SELECT COUNT(*) AS films FROM film;
```

```text
+-------+
| films |
+-------+
|  1000 |
+-------+
1 row in set (0.00 sec)
```

无论表里有什么，都是 1 行。聚合总会给出答案。

### 2) 同时使用多个聚合 {#2-several-aggregates-at-once}

```sql
SELECT MIN(length) AS shortest, MAX(length) AS longest, AVG(length) AS mean
FROM film;
```

```text
+----------+---------+----------+
| shortest | longest | mean     |
+----------+---------+----------+
|       46 |     185 | 115.2720 |
+----------+---------+----------+
1 row in set (0.00 sec)
```

每一个都读取同样的 1,000 行。请用[别名](/zh/tutorial/column-aliases)给它们命名，因为默认的标题是整个表达式。

### 3) 对金额列求和 {#3-total-a-money-column}

```sql
SELECT SUM(amount) AS takings, COUNT(*) AS payments FROM payment;
```

```text
+----------+----------+
| takings  | payments |
+----------+----------+
| 67406.56 |    16044 |
+----------+----------+
1 row in set (0.00 sec)
```

## COUNT(*) 和 COUNT(column) 是不同的问题 {#count-and-countcolumn-are-different-questions}

`COUNT(*)` 统计行数。`COUNT(column)` 统计该列有值的行数，所以它跳过 NULL。

```sql
SELECT COUNT(*) AS rows_total, COUNT(address2) AS with_a_value
FROM address;
```

```text
+------------+--------------+
| rows_total | with_a_value |
+------------+--------------+
|        603 |          599 |
+------------+--------------+
1 row in set (0.00 sec)
```

603 个地址，其中 4 个完全没有第二行地址。其余 599 个保存的是空字符串，`COUNT` 把它当作与其他值一样的值：它找的是 NULL，而不是空白。[IS NULL](/zh/tutorial/is-null) 课程介绍了这一区别。

## 每个聚合都跳过 NULL {#every-aggregate-skips-null}

这条规则并非 `COUNT` 特有。没有任何聚合会看 NULL，这意味着一个什么都没有的列没有东西可以求平均。对 id 求平均是没有意义的算术，这个查询这样做，只是因为 `original_language_id` 是 Sakila 中唯一一个在每一行都是 NULL 的列。

```sql
SELECT COUNT(*) AS films,
       COUNT(original_language_id) AS with_a_value,
       AVG(original_language_id) AS mean
FROM film;
```

```text
+-------+--------------+------+
| films | with_a_value | mean |
+-------+--------------+------+
|  1000 |            0 | NULL |
+-------+--------------+------+
1 row in set (0.00 sec)
```

`AVG` 返回的是 NULL 而不是 0，因为没有东西可以相除。这对只是有时填了值的列上的 `AVG` 最为重要：平均值是对有值的行求的，而不是对所有行，这 2 个数字并不相同。对什么都没有的东西求 `SUM` 也是 NULL，而对什么都没有的东西求 `COUNT` 是 0。

## 总结 {#summary}

- 用聚合把多行归约为 1 个值。
- 没有 `GROUP BY` 时，预期恰好返回 1 行。
- 把 `COUNT(*)` 读作有多少行，把 `COUNT(column)` 读作有多少行有值。
- 预期每个聚合都跳过 NULL，所以平均值是对有值的行求的。
- 没有符合条件的值时，预期 `SUM` 和 `AVG` 返回 NULL 而不是 0。

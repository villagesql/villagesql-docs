`COUNT(*)` 回答有多少行。`COUNT(DISTINCT column)` 回答有多少个不同的值，对于一个您还不熟悉的列，这通常是更有意思的问题。

开始之前，请用 `mysql -u root -p sakila` 打开客户端。

## COUNT DISTINCT 的工作原理 {#how-count-distinct-works}

```sql
SELECT COUNT(DISTINCT COLUMN_NAME)
FROM TABLE_NAME;
```

把 `COLUMN_NAME` 换成您要统计其不同值的列，把 `TABLE_NAME` 换成表。服务器读取每一行，丢弃重复项，然后统计剩下的。

它就是 [SELECT DISTINCT](/zh/tutorial/select-distinct) 会返回的非 NULL 行的计数，但不返回那些行。

## 示例 {#examples}

### 1) 有多少个不同的值 {#1-how-many-different-values}

```sql
SELECT COUNT(*) AS rows_total, COUNT(DISTINCT rating) AS ratings FROM film;
```

```text
+------------+---------+
| rows_total | ratings |
+------------+---------+
|       1000 |       5 |
+------------+---------+
1 row in set (0.01 sec)
```

1,000 部电影，来自 5 个分级。

### 2) 不同的组合 {#2-different-combinations}

写出多个列，一个组合只统计一次，与 `GROUP BY` 对待它们的方式相同。

```sql
SELECT COUNT(DISTINCT rating, rental_rate) AS combinations FROM film;
```

```text
+--------------+
| combinations |
+--------------+
|           15 |
+--------------+
1 row in set (0.00 sec)
```

5 个分级乘以 3 种租金，每种组合都出现了。任何一个指定列为 NULL 的行完全不被统计。

## 它跳过 NULL，这可能让答案看起来是错的 {#it-skips-null-which-can-make-the-answer-look-wrong}

`address2` 在 4 行中是 NULL，在其余 599 行中是空字符串。

```sql
SELECT COUNT(*) AS rows_total,
       COUNT(DISTINCT address2) AS distinct_values
FROM address;
```

```text
+------------+-----------------+
| rows_total | distinct_values |
+------------+-----------------+
|        603 |               1 |
+------------+-----------------+
1 row in set (0.00 sec)
```

答案是 1。空字符串是 1 个不同的值，而 NULL 被跳过了，没有被当作它自己的一个值来统计。所以当有些行是空的时候，"这一列里有多少种不同的东西"并不是这个函数回答的问题：它回答的是"有多少个不同的值"，而 NULL 是值的缺失。

当您两个数字都需要时，请用第二个查询统计缺失的行：`SELECT COUNT(*) FROM address WHERE address2 IS NULL`。

## 总结 {#summary}

- 用 `COUNT(DISTINCT column)` 统计不同的值而不是行。
- 写出多个列来统计不同的组合。
- 预期 NULL 被跳过，而不是被当作一个值统计。
- 当您两个数字都需要时，单独统计缺失的行。

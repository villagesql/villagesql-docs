Sakila 以 1 个 zip 中的 2 个 SQL 文件的形式提供。第一个建表，第二个填充数据。您按这个顺序运行它们，目标是 [安装服务器](/zh/tutorial/install-mysql) 中的那台服务器。

## 下载 {#download-it}

在您喜欢的任何目录中运行这些命令。

```bash
curl -O https://downloads.mysql.com/docs/sakila-db.zip
unzip sakila-db.zip
```

这会留下一个 `sakila-db` 目录。您需要的 2 个文件是其中的 `sakila-schema.sql` 和 `sakila-data.sql`。

## 加载 {#load-it}

先运行架构文件，再运行数据文件。如果 `root` 没有密码，在每个密码提示处按回车。

```bash
mysql -u root -p < sakila-db/sakila-schema.sql
mysql -u root -p < sakila-db/sakila-data.sql
```

成功时，两条命令在密码提示之后都不打印任何内容。数据文件需要更长时间，因为它插入数据库中的每一行。

<Note>
架构文件做的第一件事是 `DROP SCHEMA IF EXISTS sakila`。再次运行这 2 条命令会从头重建数据库，所以您总能回到一份干净的副本。您改动过的任何东西都会随之消失。
</Note>

## 在数据库内部工作 {#work-inside-the-database}

每一课写查询时都把 `sakila` 当作当前数据库。打开客户端时指定它：

```bash
mysql -u root -p sakila
```

或者进入之后切换到它：

```sql
USE sakila;
```

两种做法都不用的话，提到 `film` 的查询会失败。

```bash
mysql -u root -p -e "SELECT COUNT(*) FROM film;"
```

```text
Enter password:
ERROR 1046 (3D000) at line 1: No database selected
```

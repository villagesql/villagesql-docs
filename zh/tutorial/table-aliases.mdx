表别名是表的一个简短名字，在 1 个查询的范围内有效。它在连接中省去打字，而且两次引用同一张表的查询没有它就无法工作。

开始之前，请用 `mysql -u root -p sakila` 打开客户端。

## 表别名的工作原理 {#how-a-table-alias-works}

```sql
SELECT ALIAS_NAME.COLUMN_NAME
FROM TABLE_NAME AS ALIAS_NAME;
```

把 `TABLE_NAME` 替换为表，`ALIAS_NAME` 替换为您想要的简短名字，`COLUMN_NAME` 替换为该表的一列。从那时起，别名就是这个查询中该表的名字，您用 `ALIAS_NAME.COLUMN_NAME` 来指定它的一列。

`AS` 在这里是可选的，与列别名一样，所以 `FROM film f` 与 `FROM film AS f` 含义相同。写出 `AS` 能让意图更清楚。

## 同一个连接的 2 种写法 {#the-same-join-written-both-ways}

没有别名时，每个限定的列都带着完整的表名。

```sql
SELECT film.title, language.name
FROM film
JOIN language ON film.language_id = language.language_id
ORDER BY film.title
LIMIT 3;
```

```text
+------------------+---------+
| title            | name    |
+------------------+---------+
| ACADEMY DINOSAUR | English |
| ACE GOLDFINGER   | English |
| ADAPTATION HOLES | English |
+------------------+---------+
3 rows in set (0.00 sec)
```

有了别名，同一个查询更短，结构也更容易看清。

```sql
SELECT f.title, l.name
FROM film AS f
JOIN language AS l ON f.language_id = l.language_id
ORDER BY f.title
LIMIT 3;
```

```text
+------------------+---------+
| title            | name    |
+------------------+---------+
| ACADEMY DINOSAUR | English |
| ACE GOLDFINGER   | English |
| ADAPTATION HOLES | English |
+------------------+---------+
3 rows in set (0.00 sec)
```

相同的行。别名不会改变答案的任何部分。

## 两个表都有的列必须加限定 {#a-column-that-exists-in-both-tables-has-to-be-qualified}

`film` 和 `language` 都有 `language_id`。只写裸名字，服务器就没有办法选择。

```sql
SELECT language_id
FROM film
JOIN language ON film.language_id = language.language_id
LIMIT 1;
```

```text
ERROR 1052 (23000): Column 'language_id' in field list is ambiguous
```

`ERROR 1052` 表示服务器找到了不止 1 个这个名字可能指代的东西。在连接中，这几乎总是 2 个表共有的一列，用您所指的表或别名限定它就能解决。只有 1 个表才有的列名不需要限定，这就是为什么上面的查询中 `title` 和 `name` 可以裸写。

## 别名取代了表名 {#the-alias-replaces-the-table-name}

一旦表有了别名，原来的名字在这个查询的其余部分就不存在了。

```sql
SELECT film.title
FROM film AS f
JOIN language AS l ON f.language_id = l.language_id
LIMIT 1;
```

```text
ERROR 1054 (42S22): Unknown column 'film.title' in 'field list'
```

这个表在数据库中仍然叫 `film`。在这个查询里，它只回应 `f`，别的都不认。对一个您在表结构中看得到的名字报 `ERROR 1054`，通常就是这个原因。

## 没有别名就写不出来的情况 {#the-case-that-cannot-be-written-without-an-alias}

一个把同一个表写 2 次的查询有 2 个叫 `actor` 的东西，却无法区分它们。别名使这种查询成为可能，[自连接](/zh/tutorial/self-join)课程就建立在它之上。

## 表别名不是列别名 {#a-table-alias-is-not-a-column-alias}

它们用同一个关键字，做不同的工作。列别名重命名结果中的一列，并出现在标题中。表别名重命名查询内部的一个表，完全不出现在输出中。另一种别名请参阅[列别名](/zh/tutorial/column-aliases)。

## 总结 {#summary}

- 用 `TABLE_NAME AS ALIAS_NAME` 给表起一个在 1 个查询内有效的简短名字。
- 对查询中不止 1 个表拥有的任何列名加限定。
- 把连接中的 `ERROR 1052` 理解为您需要限定的列名。
- 当 `ERROR 1054` 指出一个您知道存在的列时，怀疑是忘了别名。
- 预期别名不会改变结果的任何部分。

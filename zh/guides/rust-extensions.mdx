VillageSQL 扩展可以使用 `villagesql` crate 以 Rust 编写。SDK 处理所有 FFI 编组 — 您编写普通的 Rust 代码，`extension!` 宏会生成服务器在加载时调用的 C 入口点。

## 何时选择 Rust {#when-to-choose-rust}

在以下情况下，Rust 是正确的选择：

- 您更喜欢 Rust，并且不需要 C++ 代码库
- 您想要内存安全，但不想要垃圾回收器
- 您正在构建一个新扩展，并且没有现有的 C++ 依赖

如果您已有 C++ 代码库，或者需要目前最完整的自定义类型构建器 API，请参阅 [编写 C++ 扩展](/zh/guides/cpp-extensions)。

<Warning>
该 API 对于扩展开发是稳定的，但自定义类型构建器 API 仍在成熟中。
</Warning>

## 先决条件 {#prerequisites}

您需要：

- **Rust stable 工具链** — 从 [rustup.rs](https://rustup.rs) 安装
- **cargo-vsql** — 用于打包、安装和测试的 Cargo 子命令

从 SDK 仓库安装 `cargo-vsql`：

```bash
git clone https://github.com/villagesql/vsql-rust-sdk
cd vsql-rust-sdk
cargo install --path cargo-vsql
```

## 创建新 Crate {#set-up-a-new-crate}

创建一个库 crate，添加 SDK，然后进行配置：

```bash
cargo new --lib vsql_my_extension
cd vsql_my_extension
cargo add villagesql
```

然后在 `Cargo.toml` 中设置 crate 类型：

```toml
[lib]
crate-type = ["cdylib"]
```

在 `Cargo.toml` 旁边添加 `manifest.json`：

```json
{
  "name": "vsql_my_extension",
  "version": "0.1.0",
  "description": "My VillageSQL extension",
  "author": "Your Name",
  "license": "GPL-2.0"
}
```

## 编写函数 {#write-a-function}

[用 Rust 构建扩展](/zh/extensions/build/rust-sdk) 页面提供了带有 ROT-13 示例的完整演练。简短版本：实现 `fn(&[InValue]) -> VdfReturn`，用 `func!` 注册它，然后用 `extension!` 包装所有内容：

```rust
use villagesql::{InValue, VdfReturn};

fn my_func_impl(args: &[InValue]) -> VdfReturn {
    match args.first() {
        Some(InValue::String(s)) => VdfReturn::string(s.to_uppercase()),
        Some(InValue::Null) | None => VdfReturn::null(),
        _ => VdfReturn::error("my_func: expected a STRING argument"),
    }
}

villagesql::extension! {
    funcs: [
        villagesql::func!(my_func_impl, "my_func", [villagesql::Type::String] -> villagesql::Type::String),
    ]
}
```

有关自定义类型（二进制存储、排序、哈希），请参阅 [Rust 中的自定义类型](/zh/sdk/rust/custom-types)。

## 测试扩展 {#test-your-extension}

在 `mysql-test/t/basic.test` 中编写测试：

```sql
INSTALL EXTENSION vsql_my_extension;
SELECT my_func('hello');
SELECT my_func(NULL);
UNINSTALL EXTENSION vsql_my_extension;
```

设置您的 VillageSQL 构建目录，生成预期结果，然后运行：

```bash
export VillageSQL_BUILD_DIR=/path/to/villagesql/build
cargo vsql test --record
cargo vsql test
```

通过的运行会为每个测试文件打印 `[ pass ]`。

## 在 SQL 中安装 {#install-in-sql}

打包并安装：

```bash
cargo vsql install
```

然后在 SQL 中：

```sql
INSTALL EXTENSION vsql_my_extension;
SELECT * FROM INFORMATION_SCHEMA.EXTENSIONS WHERE EXTENSION_NAME = 'vsql_my_extension';
SELECT my_func('hello');
-- → HELLO
```

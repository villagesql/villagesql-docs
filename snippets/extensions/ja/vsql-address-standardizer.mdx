米国の郵便住所は 1 行の自由形式テキストとして届きますが、その用途のほとんどは、番地、通り、部屋番号、市、州、ZIP コードといった各部分を必要とします。`vsql_address_standardizer` はその行を SQL で分割し、見つけたものを正規化するため、`north` は `N` に、`new york` は `NY` になります。PostgreSQL の `address_standardizer` contrib モジュールに着想を得ています。

## インストール {#install}

VillageSQL のビルドツリー (`VillageSQL_BUILD_DIR`) に対してリポジトリからビルドし、`.veb` ファイルをサーバーの `veb_dir` にコピーして、インストールします。

```sql
INSTALL EXTENSION vsql_address_standardizer;
```

## 追加される機能 {#what-it-adds}

| 関数 | 戻り値 | 説明 |
|---|---|---|
| `address_standardize(address)` | text | 住所全体を正規化し、1 行に書き直したもの |
| `address_parse_json(address)` | text | 各部分を JSON オブジェクトで返す。`house_number`、`street_name`、`street_suffix`、`city`、`state`、および `zip` は常に存在する。`pre_directional`、`post_directional`、`unit_designator`、および `unit_identifier` は住所にそれらがあるときに現れる |
| `address_field(address, name)` | text | 名前で指定した 1 つの部分 |

米国の住所のみを扱います。

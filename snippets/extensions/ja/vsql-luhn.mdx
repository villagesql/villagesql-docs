カード番号、IMEI コード、およびカナダの社会保険番号はすべて Luhn チェックディジットを持ち、手入力された識別子が壊れる最も一般的な原因は 1 桁の誤りです。`vsql_luhn` はそのチェックディジットを検証し、生成するため、`CHECK` 制約で不正な番号が行に届く前に拒否できます。

## インストール {#install}

VillageSQL のビルドツリー (`VillageSQL_BUILD_DIR`) に対してリポジトリからビルドし、`.veb` ファイルをサーバーの `veb_dir` にコピーして、インストールします。

```sql
INSTALL EXTENSION vsql_luhn;
```

## 追加される機能 {#what-it-adds}

| 関数 | 戻り値 | 説明 |
|---|---|---|
| `luhn_valid(value)` | int | 文字列がチェックサムを通れば 1、通らなければ 0。空白とハイフンは無視され、数値でないテキストはエラーではなく 0 を返す |
| `luhn_checkdigit(partial)` | text | 部分的な識別子に正しいチェックディジットを付加する |

`luhn_valid` は数値でないテキストに対して失敗せず 0 を返すため、未検証の入力を持つカラムに対する `WHERE` 句にそのまま使えます。

`vsql_hll` は、スケッチと呼ばれる固定サイズの小さな要約を使って、カラムに含まれる異なる値の数 (たとえば、サイトを訪れた異なるユーザーの数) を推定します。正確な `COUNT(DISTINCT ...)` では遅すぎる場合や、日ごとのカウントを保存しておき、元の行に戻らずに週ごとのカウントへ結合したい場合に使用します。

## インストール {#install}

VillageSQL のビルドツリー (`VillageSQL_BUILD_DIR`) に対してリポジトリからビルドし、`.veb` ファイルをサーバーの `veb_dir` にコピーして、インストールします。

```sql
INSTALL EXTENSION vsql_hll;
```

## 追加される機能 {#what-it-adds}

`hll` カラム型はスケッチを格納するため、スケッチを保存しておき、後で結合できます。

| 関数 | 戻り値 | 説明 |
|---|---|---|
| `hll_hash_bigint(number)` | 数値 | 整数をハッシュし、スケッチに追加できるようにする |
| `hll_hash_text(text)` | 数値 | テキスト値をハッシュする |
| `hll_hash_boolean(value)` | 数値 | 真偽値をハッシュする |
| `hll_hash_bytea_hex(hex_text)` | 数値 | 16 進テキストとして書かれたバイナリデータをハッシュする |
| `hll_empty()` | `hll` | 新しい空のスケッチを返す |
| `hll_add(sketch, hash)` | `hll` | ハッシュした値を 1 つスケッチに追加する |
| `hll_union(sketch_a, sketch_b)` | `hll` | 2 つのスケッチを結合し、両方に含まれる値は 1 回だけ数える |
| `hll_cardinality(sketch)` | 数値 | 異なる値の推定数を返す |
| `hll_agg(hash)` | `hll` | 集計関数: 行のグループ内のハッシュ値から 1 つのスケッチを作成する |
| `hll_union_agg(sketch)` | `hll` | 集計関数: 行のグループ内のスケッチを結合する |

スケッチに追加する前にすべての値をハッシュし、同じ種類の値には常に同じ関数を使用してください。

スラッグは URL の読める部分であり、タイトルから作るには、アクセントの除去、小文字化、句読点の区切り文字への置換、および両端の区切り文字の削除が必要です。`vsql_slugify` はそれを SQL で行うため、生成カラムがスラッグを保持し、タイトルと同期させておけます。

## インストール {#install}

VillageSQL のビルドツリー (`VillageSQL_BUILD_DIR`) に対してリポジトリからビルドし、`.veb` ファイルをサーバーの `veb_dir` にコピーして、インストールします。

```sql
INSTALL EXTENSION vsql_slugify;
```

## 追加される機能 {#what-it-adds}

| 関数 | 戻り値 | 説明 |
|---|---|---|
| `slugify(value)` | text | URL セーフなスラッグ。アクセントを除去し、文字を小文字化し、その他の文字の連続を 1 つの区切り文字にまとめ、両端の区切り文字を削除する |

メンテナーのドキュメントでは `STORED` 生成カラムでの使用例を示しており、スラッグは読み取りのたびではなく、行の書き込み時に計算されます。

`vsql_complex` は、複素数を 2 つの倍精度浮動小数点数として格納する `COMPLEX` カラム型を、それに伴う算術演算とともに追加します。カスタム型の実例としてサーバーに同梱されており、VEF 型に必要なものを端から端まで示しています。バイナリレイアウト、テキスト形式、比較規則、および集約です。

## インストール {#install}

`vsql_complex` はサーバーのソースツリーに含まれているため、そのバンドルはソースからのビルドを含むすべてのインストール方法の後に存在します。1 つのステートメントでサーバーにインストールします。

```sql
INSTALL EXTENSION vsql_complex;
```

インストールされたことを確認します。

```sql
SELECT EXTENSION_NAME
FROM INFORMATION_SCHEMA.EXTENSIONS
WHERE EXTENSION_NAME = 'vsql_complex';
```

```
+----------------+
| EXTENSION_NAME |
+----------------+
| vsql_complex   |
+----------------+
```

## 追加される機能 {#what-it-adds}

### COMPLEX 型 {#the-complex-type}

値は `'(real,imaginary)'` と書き、16 バイトを占有します。バンドルは `COMPLEX2` という変種も登録しますが、このページでは扱いません。

```sql
CREATE TABLE signals (
    id        INT PRIMARY KEY,
    impedance COMPLEX
);
```

### 関数 {#functions}

| 関数 | 戻り値 | 説明 |
|---|---|---|
| `complex_add(a, b)` | `COMPLEX` | 加算 |
| `complex_subtract(a, b)` | `COMPLEX` | 減算 |
| `complex_multiply(a, b)` | `COMPLEX` | 乗算 |
| `complex_divide(a, b)` | `COMPLEX` | 除算 |
| `complex_real(a)` | real | 実部 |
| `complex_imag(a)` | real | 虚部 |
| `complex_abs(a)` | real | 絶対値 |
| `complex_conjugate(a)` | `COMPLEX` | 共役 |
| `complex_sum(a)` | `COMPLEX` | 集約: グループ全体の合計 |

## 例 {#example}

```sql
INSERT INTO signals VALUES
    (1, '(50.0,0.0)'),
    (2, '(3.0,4.0)'),
    (3, '(0.0,-2.5)');

SELECT id, impedance,
       complex_real(impedance) AS re,
       complex_imag(impedance) AS im,
       complex_abs(impedance) AS magnitude
FROM signals;
```

```
+----+-----------+------+------+-----------+
| id | impedance | re   | im   | magnitude |
+----+-----------+------+------+-----------+
|  1 | (50,0)    |   50 |    0 |        50 |
|  2 | (3,4)     |    3 |    4 |         5 |
|  3 | (0,-2.5)  |    0 | -2.5 |       2.5 |
+----+-----------+------+------+-----------+
```

`(0,1)` を掛けると値が 4 分の 1 回転し、集約はカラム全体を合計します。

```sql
SELECT complex_multiply(impedance, '(0,1)') AS rotated FROM signals WHERE id = 2;
SELECT complex_sum(impedance) AS total FROM signals;
```

```
+---------+
| rotated |
+---------+
| (-4,3)  |
+---------+
+----------+
| total    |
+----------+
| (53,1.5) |
+----------+
```

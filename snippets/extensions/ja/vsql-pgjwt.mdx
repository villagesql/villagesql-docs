`vsql_pgjwt` は、SQL の中で JSON Web Token の署名、検証、およびデコードを行います。ストアド関数が署名済みトークンを返し、クエリがアプリケーションを呼び出すことなく渡されたトークンを検証できます。

  この拡張機能はサードパーティが作成し、保守しています。VillageSQL はこれをビルド、テスト、または提供しておらず、以下の説明はメンテナー自身のドキュメントに従っています。これに依存する前に、そのドキュメントを読んでください。
</Note>

## インストール {#install}

VillageSQL のビルドツリー (`VillageSQL_BUILD_DIR`) に対してリポジトリからビルドし、`.veb` ファイルをサーバーの `veb_dir` にコピーして、インストールします。

```sql
INSTALL EXTENSION vsql_pgjwt;
```

## 追加される機能 {#what-it-adds}

| 関数 | 戻り値 | 説明 |
|---|---|---|
| `jwt_sign(payload, secret, algorithm)` | text | ペイロードに署名し、トークンを返す |
| `jwt_verify(token, secret, algorithm)` | text | 署名を検証し、`valid`、`header`、および `payload` を持つ JSON エンベロープを返す |
| `jwt_decode(token)` | text | 署名を検証せずにトークンの内容を読む |

HMAC 署名は HS256、HS384、および HS512 として、RSA は RS256 としてサポートされます。

<Warning>
  `jwt_decode` は何も検証しません。同じトークンで `jwt_verify` が通るまで、デコードしたペイロードは事実ではなく、誰かが送ってきたテキストとして扱ってください。
</Warning>

Nano ID は、UUID が 36 文字であるのに対して 21 文字で、エスケープなしで URL に安全に使えるアルファベットから作られます。`vsql_nanoid` はそれを SQL で生成するため、公開用の識別子をアプリケーションではなく挿入時に生成できます。

## インストール {#install}

VillageSQL のビルドツリー (`VillageSQL_BUILD_DIR`) に対してリポジトリからビルドし、`.veb` ファイルをサーバーの `veb_dir` にコピーして、インストールします。乱数源として OpenSSL が必要です。

```sql
INSTALL EXTENSION vsql_nanoid;
```

## 追加される機能 {#what-it-adds}

| 関数 | 戻り値 | 説明 |
|---|---|---|
| `nanoid()` | text | デフォルトのアルファベット `A-Za-z0-9_-` からなる 21 文字の識別子 |
| `nanoid_with(size)` | text | 同上。長さを自分で選ぶ |
| `nanoid_with(size, alphabet)` | text | 同上。アルファベットを自分で選ぶ |

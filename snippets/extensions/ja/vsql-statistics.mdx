`vsql_statistics` は、MySQL にない統計集約関数を追加します。中央値と四分位数、t 検定、z 検定、一元配置分散分析、カイ二乗検定、共分散、歪度、尖度、最頻値、および 4 種類の平均です。それぞれが JSON オブジェクトを文字列として返すため、1 回の呼び出しで検定が生成するすべての数値が得られます。必要なフィールドを `JSON_EXTRACT()` で読み取ってください。

## インストール {#install}

SDK 0.0.4 以降に対してリポジトリからビルドし (`VillageSQL_BUILD_DIR` に VillageSQL のビルドツリーを指定)、`.veb` ファイルをサーバーの `veb_dir` にコピーして、サーバーにインストールします。

```sql
INSTALL EXTENSION vsql_statistics;
```

## 追加される機能 {#what-it-adds}

| ファミリー | 関数 |
|---|---|
| 四分位数と外れ値 | `STATS_IQR` は `q1`、`median`、`q3`、`iqr`、`lower_fence`、および `upper_fence` を返す |
| 2 標本 t 検定 | `STATS_TTEST`, `STATS_TTEST_GROUPS` |
| 1 標本 z 検定 | `STATS_ZTEST` |
| 一元配置分散分析 | `STATS_ANOVA` |
| カイ二乗検定 | `STATS_CHISQ_GOF`, `STATS_CHISQ_INDEP` |
| 共分散 | `STATS_COVARIANCE`。母集団と標本 |
| 形状 | `STATS_SKEWNESS`, `STATS_KURTOSIS` |
| 中心傾向 | トリム平均、ウィンザー化平均、幾何平均、および調和平均のための `STATS_MEAN` と、`STATS_MODE` |

それぞれが数値を JSON 文字列として返します。VillageSQL 0.0.7 以降では `JSON_EXTRACT()` がこれを直接読み取れます。それより前のサーバーでは、先に `CAST(... AS CHAR)` を適用してください。たとえば `STATS_IQR` は四分位数の横にフェンスを置くため、外れ値の検出はデータを 3 回走査するのではなく、1 回の集約で済みます。

O `vsql_pgjwt` assina, verifica e decodifica JSON Web Tokens dentro do SQL. Uma
função armazenada pode devolver um token assinado, e uma consulta pode
verificar um que recebeu sem chamar uma aplicação externa.

## Instalar

Compile-o a partir do repositório com uma árvore de compilação do VillageSQL (`VillageSQL_BUILD_DIR`), copie o arquivo `.veb` para o `veb_dir` do servidor e, em seguida, instale-o:

```sql
INSTALL EXTENSION vsql_pgjwt;
```

## O que ela adiciona

| Função | Retorna | O que faz |
|---|---|---|
| `jwt_sign(payload, secret, algorithm)` | texto | Assina um payload e retorna o token |
| `jwt_verify(token, secret, algorithm)` | texto | Verifica a assinatura e retorna um envelope JSON com `valid`, `header` e `payload` |
| `jwt_decode(token)` | texto | Lê o conteúdo de um token sem verificar a assinatura |

A assinatura HMAC é suportada como HS256, HS384 e HS512, e RSA como RS256.

<Warning>
  O `jwt_decode` não verifica nada. Trate um payload decodificado como texto
  que alguém lhe enviou, e não como um fato, até que o `jwt_verify` tenha
  aprovado o mesmo token.
</Warning>

O `vsql_statistics` adiciona agregados estatísticos que o MySQL não tem:
mediana e quartis, testes t, testes z, ANOVA de um fator, qui-quadrado,
covariância, assimetria, curtose, moda e quatro tipos de média. Cada um
retorna um objeto JSON como string, então uma única chamada lhe dá todos os
números que o teste produz.
Leia os campos que você quer com `JSON_EXTRACT()`.

## Instalar

Compile-o a partir do repositório com o SDK 0.0.4 ou posterior (`VillageSQL_BUILD_DIR` indica uma árvore de compilação do VillageSQL), copie o arquivo `.veb` para o `veb_dir` do servidor e, em seguida, instale-o no
servidor:

```sql
INSTALL EXTENSION vsql_statistics;
```

## O que ela adiciona

| Família | Funções |
|---|---|
| Quartis e outliers | `STATS_IQR` retorna `q1`, `median`, `q3`, `iqr`, `lower_fence` e `upper_fence` |
| Teste t de duas amostras | `STATS_TTEST`, `STATS_TTEST_GROUPS` |
| Teste z de uma amostra | `STATS_ZTEST` |
| ANOVA de um fator | `STATS_ANOVA` |
| Qui-quadrado | `STATS_CHISQ_GOF`, `STATS_CHISQ_INDEP` |
| Covariância | `STATS_COVARIANCE`, populacional e amostral |
| Forma | `STATS_SKEWNESS`, `STATS_KURTOSIS` |
| Tendência central | `STATS_MEAN` para médias aparadas, winsorizadas, geométricas e harmônicas, e `STATS_MODE` |

Cada uma retorna os seus números como uma string JSON, que o `JSON_EXTRACT()` lê diretamente no VillageSQL 0.0.7 e posteriores; em servidores anteriores, aplique `CAST(... AS CHAR)` primeiro. O `STATS_IQR`, por
exemplo, coloca as cercas ao lado dos quartis, então encontrar outliers é um
único agregado em vez de três passagens pelos dados.

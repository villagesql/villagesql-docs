Números de cartão, códigos IMEI e números de seguro social canadenses carregam
um dígito verificador de Luhn, e um dígito errado é a forma mais comum de um
identificador digitado ficar inválido. O `vsql_luhn` verifica esse dígito e o
gera, de modo que uma restrição `CHECK` pode recusar um número inválido antes
que ele chegue a uma linha.

## Instalar

Compile-o a partir do repositório com uma árvore de compilação do VillageSQL (`VillageSQL_BUILD_DIR`), copie o arquivo `.veb` para o `veb_dir` do servidor e, em seguida, instale-o:

```sql
INSTALL EXTENSION vsql_luhn;
```

## O que ela adiciona

| Função | Retorna | O que faz |
|---|---|---|
| `luhn_valid(value)` | int | 1 quando a string passa na soma de verificação, 0 quando não passa. Espaços em branco e hifens são ignorados, e texto não numérico retorna 0 em vez de um erro |
| `luhn_checkdigit(partial)` | texto | Acrescenta o dígito verificador correto a um identificador parcial |

Como o `luhn_valid` responde 0 em vez de falhar com texto que não é um número,
ele se encaixa diretamente em uma cláusula `WHERE` sobre uma coluna de entrada
não validada.

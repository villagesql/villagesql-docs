O MySQL não tem booleano. `BOOL` é um alias para `TINYINT(1)`, que aceita `5`
e `-1` tão bem quanto `1`, e os devolve sem alteração. O `vsql_boolean`
adiciona um tipo de coluna `STRICTBOOL` que armazena um byte e guarda dois
valores.

## Instalar

O `vsql_boolean.veb` já está no diretório `lib/veb/` do servidor se você
instalou o VillageSQL com o script de instalação, a imagem Docker ou um tarball
de release. Instale-o no servidor com uma única instrução:

```sql
INSTALL EXTENSION vsql_boolean;
```

Confirme que ele está lá:

```sql
SELECT EXTENSION_NAME
FROM INFORMATION_SCHEMA.EXTENSIONS
WHERE EXTENSION_NAME = 'vsql_boolean';
```

```
+----------------+
| EXTENSION_NAME |
+----------------+
| vsql_boolean   |
+----------------+
```

Para compilá-lo você mesmo, siga as instruções de compilação no
[repositório](https://github.com/villagesql/vsql-boolean).

## O que ela adiciona

### O tipo STRICTBOOL

Uma coluna `STRICTBOOL` aceita as strings `'true'`/`'false'`, `'t'`/`'f'`,
`'yes'`/`'no'`, `'on'`/`'off'` e `'1'`/`'0'`, em qualquer combinação de
maiúsculas e minúsculas. Passe-as como strings: um número sem aspas é recusado.
Ela é lida como `true` ou `false`, qualquer que seja a forma que entrou, e
ocupa um byte.

```sql
CREATE TABLE flags (
    id     INT PRIMARY KEY,
    name   VARCHAR(16),
    active STRICTBOOL
);
```

### Funções

| Função | Retorna | O que faz |
|---|---|---|
| `boolean_to_int(b)` | int | 1 para true, 0 para false |
| `boolean_sum(b)` | int | Agregado: quantas linhas do grupo são true |
| `boolean_avg(b)` | real | Agregado: a fração que é true, ignorando NULLs |

## Exemplo

```sql
INSERT INTO flags VALUES
    (1, 'alpha', 'true'),
    (2, 'beta',  'no'),
    (3, 'gamma', 'on'),
    (4, 'delta', '0');

SELECT name, active FROM flags;
```

```
+-------+--------+
| name  | active |
+-------+--------+
| alpha | true   |
| beta  | false  |
| gamma | true   |
| delta | false  |
+-------+--------+
```

Quatro grafias entraram, e dois valores saíram. Conte-os:

```sql
SELECT boolean_sum(active) AS enabled, ROUND(boolean_avg(active), 2) AS fraction
FROM flags;
```

```
+---------+----------+
| enabled | fraction |
+---------+----------+
|       2 |      0.5 |
+---------+----------+
```

<Note>
  Qualquer coisa fora das grafias aceitas é recusada no momento da inserção:
  `INSERT INTO flags VALUES (5, 'eps', 'maybe')` falha com
  `ERROR 1366 (HY000): Incorrect STRICTBOOL value: 'maybe' for column 'active'
  at row 1`. O mesmo acontece com um `1` sem aspas, com
  `ERROR 3219 (HY000): Incorrect STRICTBOOL value: '1' for column 'active' at
  row 1`.
</Note>

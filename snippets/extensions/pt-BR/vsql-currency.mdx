Uma coluna de código de moeda normalmente é um `CHAR(3)` que aceita quaisquer
três letras, incluindo as que não são moedas. O `vsql_currency` adiciona um
tipo `currency` que guarda os 164 códigos ISO 4217 que o pg-currency suporta,
em um único byte, aceita-os em qualquer combinação de maiúsculas e minúsculas
e os exibe na forma canônica em maiúsculas.

## Instalar

O `vsql_currency` não vem incluído com o servidor, então compile-o primeiro a
partir do repositório e copie o `vsql_currency.veb` resultante para o
diretório indicado pela variável de sistema `veb_dir`. Em seguida, instale-o:

```sql
INSTALL EXTENSION vsql_currency;
```

Confirme que ele está lá:

```sql
SELECT EXTENSION_NAME
FROM INFORMATION_SCHEMA.EXTENSIONS
WHERE EXTENSION_NAME = 'vsql_currency';
```

```
+----------------+
| EXTENSION_NAME |
+----------------+
| vsql_currency  |
+----------------+
```

As instruções de compilação estão no
[repositório](https://github.com/villagesql/vsql-currency).

## O que ela adiciona

### O tipo currency

```sql
CREATE TABLE prices (
    sku    VARCHAR(8) PRIMARY KEY,
    amount DECIMAL(10,2),
    unit   currency
);
```

### Funções

| Função | Retorna | O que faz |
|---|---|---|
| `currency_count()` | int | Quantos códigos a extensão conhece |
| `is_currency(code)` | int | 1 quando a string é um código ISO 4217 válido, 0 quando não é |
| `supported_currencies(prefix)` | texto | A lista de códigos como um array JSON, restrita por um prefixo |

## Exemplo

Escreva os códigos em qualquer combinação de maiúsculas e minúsculas, e leia-os de volta na forma canônica e em ordem:

```sql
INSERT INTO prices VALUES
    ('A-100', 19.99, 'usd'),
    ('A-101', 24.50, 'EUR'),
    ('A-102', 3100,  'jpy');

SELECT sku, amount, unit FROM prices ORDER BY unit;
```

```
+-------+---------+------+
| sku   | amount  | unit |
+-------+---------+------+
| A-101 |   24.50 | EUR  |
| A-102 | 3100.00 | JPY  |
| A-100 |   19.99 | USD  |
+-------+---------+------+
```

Verifique um código antes de confiar nele, e liste os que lhe interessam:

```sql
SELECT currency_count() AS codes, is_currency('XYZ') AS xyz, is_currency('GBP') AS gbp;
```

```
+-------+------+------+
| codes | xyz  | gbp  |
+-------+------+------+
|   164 |    0 |    1 |
+-------+------+------+
```

```sql
SELECT supported_currencies('C') AS starting_with_c;
```

```
+---------------------------------------------------------------------+
| starting_with_c                                                     |
+---------------------------------------------------------------------+
| ["CAD","CDF","CHF","CLP","CNY","COP","CRC","CUC","CUP","CVE","CZK"] |
+---------------------------------------------------------------------+
```

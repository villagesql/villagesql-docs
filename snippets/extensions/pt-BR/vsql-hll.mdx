O `vsql_hll` estima quantos valores diferentes uma coluna contém, como quantos
usuários diferentes visitaram um site, usando um resumo pequeno e de tamanho
fixo chamado sketch. Use-o quando um `COUNT(DISTINCT ...)` exato for lento
demais, ou quando você quiser armazenar contagens diárias e combiná-las em
contagens semanais sem voltar às linhas originais.

## Instalar

Compile-o a partir do repositório com uma árvore de compilação do VillageSQL (`VillageSQL_BUILD_DIR`), copie o arquivo `.veb` para o `veb_dir` do servidor e, em seguida, instale-o:

```sql
INSTALL EXTENSION vsql_hll;
```

## O que ela adiciona

Um tipo de coluna `hll` armazena um sketch, para que você possa salvá-lo e combiná-lo depois.

| Função | Retorna | O que faz |
|---|---|---|
| `hll_hash_bigint(number)` | número | Gera o hash de um número inteiro para que ele possa ser adicionado a um sketch |
| `hll_hash_text(text)` | número | Gera o hash de um valor de texto |
| `hll_hash_boolean(value)` | número | Gera o hash de um valor verdadeiro ou falso |
| `hll_hash_bytea_hex(hex_text)` | número | Gera o hash de dados binários escritos como texto hexadecimal |
| `hll_empty()` | `hll` | Retorna um sketch novo e vazio |
| `hll_add(sketch, hash)` | `hll` | Adiciona um valor com hash a um sketch |
| `hll_union(sketch_a, sketch_b)` | `hll` | Combina dois sketches, contando uma única vez um valor presente em ambos |
| `hll_cardinality(sketch)` | número | Retorna o número estimado de valores diferentes |
| `hll_agg(hash)` | `hll` | Agregação: constrói um sketch a partir dos valores com hash de um grupo de linhas |
| `hll_union_agg(sketch)` | `hll` | Agregação: combina os sketches de um grupo de linhas |

Gere o hash de cada valor antes de adicioná-lo a um sketch, e sempre gere o
hash do mesmo tipo de valor com a mesma função.

slug 是 URL 中可读的部分，从标题生成 slug 意味着折叠重音、转为小写、
用分隔符替换标点，并去掉两端的分隔符。`vsql_slugify` 在 SQL 中完成
这些工作，这意味着生成列可以保存 slug 并让它与标题保持一致。

## 安装 {#install}

针对 VillageSQL 构建树（`VillageSQL_BUILD_DIR`）从存储库构建它，将 `.veb` 文件复制到服务器的 `veb_dir` 中，然后安装它：

```sql
INSTALL EXTENSION vsql_slugify;
```

## 新增内容 {#what-it-adds}

| 函数 | 返回 | 作用 |
|---|---|---|
| `slugify(value)` | 文本 | 一个 URL 安全的 slug：重音已折叠，字母已转为小写，连续的其他字符合并为一个分隔符，两端的分隔符已去除 |

维护者的文档展示了它在 `STORED` 生成列中的用法，这样 slug 在写入行时
计算一次，而不是每次读取时都计算。

Nano ID 只有 21 个字符，而 UUID 有 36 个，它的字符取自一个无需转义
即可安全用于 URL 的字母表。`vsql_nanoid` 在 SQL 中生成它们，因此
面向公众的标识符可以在插入时生成，而不是在您的应用程序中生成。

## 安装 {#install}

针对 VillageSQL 构建树（`VillageSQL_BUILD_DIR`）从存储库构建它，将 `.veb` 文件复制到服务器的 `veb_dir` 中，然后安装它。它需要 OpenSSL
作为随机源。

```sql
INSTALL EXTENSION vsql_nanoid;
```

## 新增内容 {#what-it-adds}

| 函数 | 返回 | 作用 |
|---|---|---|
| `nanoid()` | 文本 | 使用默认字母表 `A-Za-z0-9_-` 生成的 21 字符标识符 |
| `nanoid_with(size)` | 文本 | 同上，长度由您指定 |
| `nanoid_with(size, alphabet)` | 文本 | 同上，字母表由您指定 |

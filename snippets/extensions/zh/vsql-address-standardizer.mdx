美国邮政地址以一行自由格式文本的形式到达，而几乎每一种用途都需要
它的组成部分：门牌号、街道、单元、城市、州、邮编。
`vsql_address_standardizer` 在 SQL 中把这一行拆开，并对找到的内容
进行规范化，因此 `north` 变成 `N`，`new york` 变成 `NY`。
它的灵感来自 PostgreSQL 的 `address_standardizer` contrib 模块。

## 安装 {#install}

针对 VillageSQL 构建树（`VillageSQL_BUILD_DIR`）从存储库构建它，将 `.veb` 文件复制到服务器的 `veb_dir` 中，然后安装它：

```sql
INSTALL EXTENSION vsql_address_standardizer;
```

## 新增内容 {#what-it-adds}

| 函数 | 返回 | 作用 |
|---|---|---|
| `address_standardize(address)` | 文本 | 整个地址，规范化后重写为一行 |
| `address_parse_json(address)` | 文本 | 以 JSON 对象表示的各个部分。`house_number`、`street_name`、`street_suffix`、`city`、`state` 和 `zip` 始终存在；`pre_directional`、`post_directional`、`unit_designator` 和 `unit_identifier` 在地址包含它们时出现 |
| `address_field(address, name)` | 文本 | 单独返回一个指定的部分 |

它只处理美国地址。

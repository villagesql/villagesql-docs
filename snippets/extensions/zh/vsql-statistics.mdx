`vsql_statistics` 添加了 MySQL 没有的统计聚合函数：中位数和四分位数、
t 检验、z 检验、单因素方差分析（ANOVA）、卡方检验、协方差、偏度、
峰度、众数，以及四种均值。每个函数都以字符串形式返回一个 JSON 对象，
因此一次调用就能得到该检验产生的每一个数字。
用 `JSON_EXTRACT()` 读取您需要的字段。

## 安装 {#install}

针对 SDK 0.0.4 或更高版本从存储库构建它（`VillageSQL_BUILD_DIR` 指向一个 VillageSQL 构建树），将 `.veb` 文件复制到服务器的 `veb_dir` 中，然后
将它安装到服务器中：

```sql
INSTALL EXTENSION vsql_statistics;
```

## 新增内容 {#what-it-adds}

| 类别 | 函数 |
|---|---|
| 四分位数和离群值 | `STATS_IQR` 返回 `q1`、`median`、`q3`、`iqr`、`lower_fence` 和 `upper_fence` |
| 双样本 t 检验 | `STATS_TTEST`、`STATS_TTEST_GROUPS` |
| 单样本 z 检验 | `STATS_ZTEST` |
| 单因素方差分析 | `STATS_ANOVA` |
| 卡方检验 | `STATS_CHISQ_GOF`、`STATS_CHISQ_INDEP` |
| 协方差 | `STATS_COVARIANCE`，总体和样本 |
| 分布形状 | `STATS_SKEWNESS`、`STATS_KURTOSIS` |
| 集中趋势 | `STATS_MEAN`（截尾均值、缩尾均值、几何均值和调和均值）以及 `STATS_MODE` |

每个函数都以 JSON 字符串返回其数字，在 VillageSQL 0.0.7 及更高版本上 `JSON_EXTRACT()` 可以直接读取；在更早的服务器上，请先应用 `CAST(... AS CHAR)`。例如，
`STATS_IQR` 把围栏值放在四分位数旁边，因此查找离群值只需一次聚合，
而不是对数据扫描三遍。

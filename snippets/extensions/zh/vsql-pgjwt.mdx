`vsql_pgjwt` 在 SQL 中签名、验证和解码 JSON Web Token。存储函数可以
返回一个已签名的令牌，查询可以检查收到的令牌，而无需调用应用程序。

## 安装 {#install}

针对 VillageSQL 构建树（`VillageSQL_BUILD_DIR`）从存储库构建它，将 `.veb` 文件复制到服务器的 `veb_dir` 中，然后安装它：

```sql
INSTALL EXTENSION vsql_pgjwt;
```

## 新增内容 {#what-it-adds}

| 函数 | 返回 | 作用 |
|---|---|---|
| `jwt_sign(payload, secret, algorithm)` | 文本 | 对载荷签名并返回令牌 |
| `jwt_verify(token, secret, algorithm)` | 文本 | 检查签名并返回包含 `valid`、`header` 和 `payload` 的 JSON 信封 |
| `jwt_decode(token)` | 文本 | 读取令牌内容，不检查签名 |

HMAC 签名支持 HS256、HS384 和 HS512，RSA 支持 RS256。

<Warning>
  `jwt_decode` 不验证任何内容。在 `jwt_verify` 对同一令牌验证通过之前，
  请把解码出的载荷当作别人发给您的文本，而不是事实。
</Warning>

卡号、IMEI 码和加拿大社会保险号都带有 Luhn 校验位，而输错一位数字
是手动输入的标识符出错的最常见方式。`vsql_luhn` 检查并生成该校验位，
因此 `CHECK` 约束可以在错误的号码写入行之前拒绝它。

## 安装 {#install}

针对 VillageSQL 构建树（`VillageSQL_BUILD_DIR`）从存储库构建它，将 `.veb` 文件复制到服务器的 `veb_dir` 中，然后安装它：

```sql
INSTALL EXTENSION vsql_luhn;
```

## 新增内容 {#what-it-adds}

| 函数 | 返回 | 作用 |
|---|---|---|
| `luhn_valid(value)` | 整数 | 字符串通过校验和时为 1，否则为 0。空白和连字符会被忽略，非数字文本返回 0 而不是报错 |
| `luhn_checkdigit(partial)` | 文本 | 为不完整的标识符追加正确的校验位 |

由于 `luhn_valid` 对非数字文本返回 0 而不是失败，它可以直接用在
针对未经验证输入列的 `WHERE` 子句中。

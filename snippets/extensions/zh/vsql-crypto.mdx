`vsql_crypto` 为 MySQL 带来一组与 `pgcrypto` 兼容的函数，基于 OpenSSL
构建。它覆盖四项工作：对值做哈希、对载荷签名、加密列，以及存储一个
以后可以验证的密码。

| | |
|---|---|
| **维护者** | VillageSQL |
| **源代码和完整文档** | [villagesql/vsql-crypto](https://github.com/villagesql/vsql-crypto) |

## 安装 {#install}

如果您使用安装脚本、Docker 镜像或发行版压缩包安装了 VillageSQL，
`vsql_crypto.veb` 已经位于服务器的 `lib/veb/` 目录中。
用一条语句将它安装到服务器中：

```sql
INSTALL EXTENSION vsql_crypto;
```

确认它已存在：

```sql
SELECT EXTENSION_NAME
FROM INFORMATION_SCHEMA.EXTENSIONS
WHERE EXTENSION_NAME = 'vsql_crypto';
```

```
+----------------+
| EXTENSION_NAME |
+----------------+
| vsql_crypto    |
+----------------+
```

要自行构建，请按照[存储库](https://github.com/villagesql/vsql-crypto)中的
构建说明进行操作。

## 新增内容 {#what-it-adds}

| 函数 | 返回 | 作用 |
|---|---|---|
| `digest(data, algorithm)` | 二进制 | 用 `md5`、`sha1`、`sha224`、`sha256`、`sha384` 或 `sha512` 对数据做哈希 |
| `hmac(data, key, algorithm)` | 二进制 | 用带密钥的哈希对数据签名 |
| `encrypt(data, key, type)` | 二进制 | 用 AES 加密 |
| `decrypt(data, key, type)` | 文本 | 用同一密钥还原 `encrypt` 的结果 |
| `crypt(password, salt)` | 文本 | 把密码哈希为一个自带参数的字符串 |
| `gen_salt(type, iterations)` | 文本 | 为 `crypt` 生成盐，仅支持 `pbkdf2-sha256` 和 `pbkdf2-sha512` |
| `gen_random_bytes(n)` | 二进制 | 密码学安全的随机字节 |
| `gen_random_uuid()` | 文本 | 以文本形式返回的随机版本 4 UUID |
| `crypto_version()` | 文本 | 扩展所链接的 OpenSSL 版本 |

标为二进制的函数返回原始字节，因此请用 `HEX()` 包装后再读取。
其余函数返回文本。

<Info>
**0.0.8-dev 中的变更。** 在 `vsql_crypto` 0.0.8 中，`digest`、`hmac`、`encrypt`、`decrypt` 和 `gen_random_bytes` 返回 `binary` 字符集。要读取 `decrypt` 返回的文本，请转换它：`CONVERT(decrypt(data, key, type) USING utf8mb4)`。`vsql_crypto` 0.0.8 需要比 0.0.7 更新的服务器。0.0.7 服务器可以安装它，但其函数随后会返回 `NULL` 或使服务器崩溃。
</Info>

## 示例 {#example}

对载荷签名：

```sql
SET @secret = 'shared-key';
SELECT HEX(hmac('{"order":4711}', @secret, 'sha256')) AS signature;
```

```
+------------------------------------------------------------------+
| signature                                                        |
+------------------------------------------------------------------+
| 7261870227EF8090041AB514536550671974770FCE19416ABB634C55389C3141 |
+------------------------------------------------------------------+
```

存储密码。结果自带算法、迭代次数和盐，因此验证时不需要在旁边额外
保存任何东西：

```sql
SELECT crypt('correct horse battery', gen_salt('pbkdf2-sha256', 100000)) AS hash;
```

```
+------------------------------------------------------------------------------------------+
| hash                                                                                     |
+------------------------------------------------------------------------------------------+
| $pbkdf2-sha256$100000$N6MXcYhD7SS4DS9sVhaQag$rv6zFwkwfo4N8+lgEpU5/LR4mOLtio04b6iKCSRlF5E |
+------------------------------------------------------------------------------------------+
```

您的盐是随机的，因此每次调用得到的哈希都不同。

<Note>
  `gen_salt` 仅支持 `pbkdf2-sha256` 和 `pbkdf2-sha512`。请求 `bf`、`md5` 或 `des`
  会返回 NULL，而盐为 NULL 时 `crypt` 也返回 NULL，因此由 `pgcrypto`
  写入的 bcrypt 哈希无法在这里验证。
</Note>

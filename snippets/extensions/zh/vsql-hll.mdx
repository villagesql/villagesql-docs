`vsql_hll` 估算一列中有多少个不同的值，例如有多少个不同的用户访问了某个网站，
它使用一种称为 sketch 的固定大小的小型摘要。当精确的 `COUNT(DISTINCT ...)`
太慢，或者您想存储每日计数并把它们合并为每周计数而无需回到原始行时，可以使用它。

## 安装 {#install}

针对 VillageSQL 构建树（`VillageSQL_BUILD_DIR`）从存储库构建它，将 `.veb` 文件复制到服务器的 `veb_dir` 中，然后安装它：

```sql
INSTALL EXTENSION vsql_hll;
```

## 新增内容 {#what-it-adds}

`hll` 列类型存储一个 sketch，因此您可以保存它，之后再合并。

| 函数 | 返回 | 作用 |
|---|---|---|
| `hll_hash_bigint(number)` | 数字 | 对整数做哈希，使其可以添加到 sketch 中 |
| `hll_hash_text(text)` | 数字 | 对文本值做哈希 |
| `hll_hash_boolean(value)` | 数字 | 对 true 或 false 值做哈希 |
| `hll_hash_bytea_hex(hex_text)` | 数字 | 对以十六进制文本表示的二进制数据做哈希 |
| `hll_empty()` | `hll` | 返回一个新的空 sketch |
| `hll_add(sketch, hash)` | `hll` | 向 sketch 添加一个哈希值 |
| `hll_union(sketch_a, sketch_b)` | `hll` | 合并两个 sketch，同时出现在两者中的值只计一次 |
| `hll_cardinality(sketch)` | 数字 | 返回不同值的估算数量 |
| `hll_agg(hash)` | `hll` | 聚合：用一组行中的哈希值构建一个 sketch |
| `hll_union_agg(sketch)` | `hll` | 聚合：合并一组行中的 sketch |

先对每个值做哈希，再把它添加到 sketch 中；对同一类值，始终使用同一个函数做哈希。

`vsql_complex`는 복소수를 double 두 개로 저장하는 `COMPLEX` 열 유형과 그에
맞는 산술 연산을 추가합니다. 사용자 정의 유형의 작동 예제로 서버 안에 함께
제공되며, VEF 유형에 처음부터 끝까지 무엇이 필요한지 보여 줍니다: 이진 레이아웃,
텍스트 형식, 비교 규칙, 집계 함수입니다.

## 설치 {#install}

`vsql_complex`는 서버 소스 트리에 들어 있으므로, 소스 빌드를 포함한 모든 설치
방법에서 번들이 존재합니다. 문 하나로 서버에 설치하세요:

```sql
INSTALL EXTENSION vsql_complex;
```

설치되었는지 확인합니다:

```sql
SELECT EXTENSION_NAME
FROM INFORMATION_SCHEMA.EXTENSIONS
WHERE EXTENSION_NAME = 'vsql_complex';
```

```
+----------------+
| EXTENSION_NAME |
+----------------+
| vsql_complex   |
+----------------+
```

## 추가되는 기능 {#what-it-adds}

### COMPLEX 유형 {#the-complex-type}

값은 `'(real,imaginary)'` 형식으로 쓰며 16바이트를 차지합니다. 번들은
`COMPLEX2` 변형도 등록하지만, 이 페이지에서는 다루지 않습니다.

```sql
CREATE TABLE signals (
    id        INT PRIMARY KEY,
    impedance COMPLEX
);
```

### 함수 {#functions}

| 함수 | 반환값 | 설명 |
|---|---|---|
| `complex_add(a, b)` | `COMPLEX` | 덧셈 |
| `complex_subtract(a, b)` | `COMPLEX` | 뺄셈 |
| `complex_multiply(a, b)` | `COMPLEX` | 곱셈 |
| `complex_divide(a, b)` | `COMPLEX` | 나눗셈 |
| `complex_real(a)` | real | 실수부 |
| `complex_imag(a)` | real | 허수부 |
| `complex_abs(a)` | real | 크기 |
| `complex_conjugate(a)` | `COMPLEX` | 켤레 복소수 |
| `complex_sum(a)` | `COMPLEX` | 집계: 그룹 전체의 합 |

## 예제 {#example}

```sql
INSERT INTO signals VALUES
    (1, '(50.0,0.0)'),
    (2, '(3.0,4.0)'),
    (3, '(0.0,-2.5)');

SELECT id, impedance,
       complex_real(impedance) AS re,
       complex_imag(impedance) AS im,
       complex_abs(impedance) AS magnitude
FROM signals;
```

```
+----+-----------+------+------+-----------+
| id | impedance | re   | im   | magnitude |
+----+-----------+------+------+-----------+
|  1 | (50,0)    |   50 |    0 |        50 |
|  2 | (3,4)     |    3 |    4 |         5 |
|  3 | (0,-2.5)  |    0 | -2.5 |       2.5 |
+----+-----------+------+------+-----------+
```

`(0,1)`을 곱하면 값이 4분의 1바퀴 회전하고, 집계 함수는 열 전체를 더합니다:

```sql
SELECT complex_multiply(impedance, '(0,1)') AS rotated FROM signals WHERE id = 2;
SELECT complex_sum(impedance) AS total FROM signals;
```

```
+---------+
| rotated |
+---------+
| (-4,3)  |
+---------+
+----------+
| total    |
+----------+
| (53,1.5) |
+----------+
```

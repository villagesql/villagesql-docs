슬러그는 URL에서 사람이 읽을 수 있는 부분이며, 제목에서 슬러그를 만들려면 악센트를
제거하고, 소문자로 바꾸고, 문장 부호를 구분자로 바꾸고, 양 끝의 구분자를 잘라내야
합니다. `vsql_slugify`는 이를 SQL에서 수행하므로, 생성된 열이 슬러그를 담고
제목과 함께 최신 상태를 유지할 수 있습니다.

## 설치 {#install}

저장소에서 VillageSQL 빌드 트리(`VillageSQL_BUILD_DIR`)를 기준으로 빌드하고, `.veb` 파일을 서버의 `veb_dir`에 복사한 다음 설치합니다:

```sql
INSTALL EXTENSION vsql_slugify;
```

## 추가되는 기능 {#what-it-adds}

| 함수 | 반환값 | 설명 |
|---|---|---|
| `slugify(value)` | text | URL에 안전한 슬러그: 악센트를 제거하고, 글자를 소문자로 바꾸고, 연속된 그 외 문자를 구분자 하나로 합치고, 양 끝의 구분자를 잘라냄 |

관리자의 문서는 이 함수를 `STORED` 생성 열에서 사용하는 예를 보여 주므로,
슬러그는 읽을 때마다가 아니라 행을 쓸 때 계산됩니다.

`vsql_hll`은 스케치라고 부르는 고정 크기의 작은 요약을 사용하여, 사이트를 방문한
서로 다른 사용자 수처럼 열에 서로 다른 값이 몇 개 있는지 추정합니다. 정확한
`COUNT(DISTINCT ...)`가 너무 느릴 때, 또는 일별 개수를 저장해 두었다가 원시 행으로
돌아가지 않고 주별 개수로 합치고 싶을 때 사용하세요.

## 설치 {#install}

저장소에서 VillageSQL 빌드 트리(`VillageSQL_BUILD_DIR`)를 기준으로 빌드하고, `.veb` 파일을 서버의 `veb_dir`에 복사한 다음 설치합니다:

```sql
INSTALL EXTENSION vsql_hll;
```

## 추가되는 기능 {#what-it-adds}

`hll` 열 유형은 스케치를 저장하므로, 스케치를 저장해 두었다가 나중에 합칠 수 있습니다.

| 함수 | 반환값 | 설명 |
|---|---|---|
| `hll_hash_bigint(number)` | number | 정수를 스케치에 추가할 수 있도록 해시 |
| `hll_hash_text(text)` | number | 텍스트 값을 해시 |
| `hll_hash_boolean(value)` | number | 참 또는 거짓 값을 해시 |
| `hll_hash_bytea_hex(hex_text)` | number | 16진수 텍스트로 쓴 바이너리 데이터를 해시 |
| `hll_empty()` | `hll` | 비어 있는 새 스케치를 반환 |
| `hll_add(sketch, hash)` | `hll` | 해시된 값 하나를 스케치에 추가 |
| `hll_union(sketch_a, sketch_b)` | `hll` | 두 스케치를 합치며, 양쪽에 모두 있는 값은 한 번만 셈 |
| `hll_cardinality(sketch)` | number | 서로 다른 값의 추정 개수를 반환 |
| `hll_agg(hash)` | `hll` | 집계: 행 그룹의 해시된 값으로 스케치 하나를 만듦 |
| `hll_union_agg(sketch)` | `hll` | 집계: 행 그룹의 스케치들을 합침 |

모든 값은 스케치에 추가하기 전에 해시하고, 같은 종류의 값은 항상 같은 함수로
해시하세요.

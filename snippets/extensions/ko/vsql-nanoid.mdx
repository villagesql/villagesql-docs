Nano ID는 UUID가 36자인 데 비해 21자이며, 이스케이프 없이 URL에 안전하게 쓸 수
있는 알파벳으로 만들어집니다. `vsql_nanoid`는 이를 SQL에서 생성하므로, 외부에
공개되는 식별자를 애플리케이션이 아니라 삽입 시점에 만들 수 있습니다.

## 설치 {#install}

저장소에서 VillageSQL 빌드 트리(`VillageSQL_BUILD_DIR`)를 기준으로 빌드하고, `.veb` 파일을 서버의 `veb_dir`에 복사한 다음 설치합니다. 난수 소스로
OpenSSL이 필요합니다.

```sql
INSTALL EXTENSION vsql_nanoid;
```

## 추가되는 기능 {#what-it-adds}

| 함수 | 반환값 | 설명 |
|---|---|---|
| `nanoid()` | text | 기본 알파벳 `A-Za-z0-9_-`로 만든 21자 식별자 |
| `nanoid_with(size)` | text | 같은 식별자를 원하는 길이로 생성 |
| `nanoid_with(size, alphabet)` | text | 같은 식별자를 원하는 알파벳으로 생성 |

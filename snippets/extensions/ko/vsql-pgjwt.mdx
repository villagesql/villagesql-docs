`vsql_pgjwt`는 SQL 안에서 JSON Web Token을 서명, 검증, 디코딩합니다. 저장
함수가 서명된 토큰을 돌려줄 수 있고, 쿼리가 애플리케이션을 호출하지 않고도 받은
토큰을 확인할 수 있습니다.

<Note>
  이 확장 기능은 제3자가 작성하고 관리합니다. VillageSQL은 이를 빌드, 테스트,
  배포하지 않으며, 아래 설명은 관리자의 자체 문서를 따릅니다. 이 확장 기능에
  의존하기 전에 해당 문서를 읽으세요.
</Note>

## 설치 {#install}

저장소에서 VillageSQL 빌드 트리(`VillageSQL_BUILD_DIR`)를 기준으로 빌드하고, `.veb` 파일을 서버의 `veb_dir`에 복사한 다음 설치합니다:

```sql
INSTALL EXTENSION vsql_pgjwt;
```

## 추가되는 기능 {#what-it-adds}

| 함수 | 반환값 | 설명 |
|---|---|---|
| `jwt_sign(payload, secret, algorithm)` | text | 페이로드에 서명하고 토큰을 반환 |
| `jwt_verify(token, secret, algorithm)` | text | 서명을 확인하고 `valid`, `header`, `payload`를 담은 JSON 봉투를 반환 |
| `jwt_decode(token)` | text | 서명을 확인하지 않고 토큰의 내용을 읽음 |

HMAC 서명은 HS256, HS384, HS512로, RSA 서명은 RS256으로 지원됩니다.

<Warning>
  `jwt_decode`는 아무것도 검증하지 않습니다. 같은 토큰에 대해 `jwt_verify`가
  통과하기 전까지는, 디코딩된 페이로드를 사실이 아니라 누군가가 보낸 텍스트로
  취급하세요.
</Warning>

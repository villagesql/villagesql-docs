미국 우편 주소는 자유 형식 텍스트 한 줄로 들어오지만, 거의 모든 용도에서 그
구성 요소가 필요합니다: 건물 번호, 거리, 호수, 도시, 주, ZIP입니다.
`vsql_address_standardizer`는 그 줄을 SQL에서 분리하고 찾은 내용을
정규화하므로, `north`는 `N`이 되고 `new york`은 `NY`가 됩니다. PostgreSQL의
`address_standardizer` contrib 모듈에서 영감을 받았습니다.

## 설치 {#install}

저장소에서 VillageSQL 빌드 트리(`VillageSQL_BUILD_DIR`)를 기준으로 빌드하고, `.veb` 파일을 서버의 `veb_dir`에 복사한 다음 설치합니다:

```sql
INSTALL EXTENSION vsql_address_standardizer;
```

## 추가되는 기능 {#what-it-adds}

| 함수 | 반환값 | 설명 |
|---|---|---|
| `address_standardize(address)` | text | 주소 전체를 정규화하여 한 줄로 다시 쓴 결과 |
| `address_parse_json(address)` | text | 구성 요소를 JSON 객체로 반환. `house_number`, `street_name`, `street_suffix`, `city`, `state`, `zip`은 항상 포함되고, `pre_directional`, `post_directional`, `unit_designator`, `unit_identifier`는 주소에 있을 때 포함 |
| `address_field(address, name)` | text | 이름으로 지정한 구성 요소 하나 |

미국 주소만 처리합니다.

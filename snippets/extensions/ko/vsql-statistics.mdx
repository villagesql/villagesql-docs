`vsql_statistics`는 MySQL에 없는 통계 집계 함수를 추가합니다: 중앙값과
사분위수, t-검정, z-검정, 일원 분산 분석(ANOVA), 카이제곱, 공분산, 왜도, 첨도,
최빈값, 그리고 네 종류의 평균입니다. 각 함수는 JSON 객체를 문자열로 반환하므로,
호출 한 번으로 검정이 산출하는 모든 수치를 얻습니다.
`JSON_EXTRACT()`로 원하는 필드를 읽으세요.

## 설치 {#install}

저장소에서 SDK 0.0.4 이상을 기준으로 빌드하고(`VillageSQL_BUILD_DIR`은 VillageSQL 빌드 트리를 가리킴), `.veb` 파일을 서버의 `veb_dir`에 복사한 다음
서버에 설치합니다:

```sql
INSTALL EXTENSION vsql_statistics;
```

## 추가되는 기능 {#what-it-adds}

| 계열 | 함수 |
|---|---|
| 사분위수와 이상값 | `STATS_IQR`은 `q1`, `median`, `q3`, `iqr`, `lower_fence`, `upper_fence`를 반환 |
| 이표본 t-검정 | `STATS_TTEST`, `STATS_TTEST_GROUPS` |
| 일표본 z-검정 | `STATS_ZTEST` |
| 일원 분산 분석 | `STATS_ANOVA` |
| 카이제곱 | `STATS_CHISQ_GOF`, `STATS_CHISQ_INDEP` |
| 공분산 | `STATS_COVARIANCE`, 모집단과 표본 |
| 분포 형태 | `STATS_SKEWNESS`, `STATS_KURTOSIS` |
| 중심 경향 | 절사 평균, 윈저화 평균, 기하 평균, 조화 평균용 `STATS_MEAN`과 `STATS_MODE` |

모든 함수는 수치를 JSON 문자열로 반환하며, VillageSQL 0.0.7 이상에서는 `JSON_EXTRACT()`가 이를 바로 읽습니다. 이전 서버에서는 먼저 `CAST(... AS CHAR)`를 적용하세요. 예를 들어
`STATS_IQR`은 사분위수 옆에 울타리 값을 함께 두므로, 이상값을 찾는 일이 데이터를
세 번 훑는 대신 집계 한 번으로 끝납니다.

## Instalar com o script de instalação

```bash
curl -fsSL https://install.villagesql.com | bash
```

O script pergunta qual base de código instalar (MySQL 8.4, Percona Server 8.4 ou MySQL 9.7) e como instalá-la: um download pré-compilado, Docker ou uma compilação a partir do código-fonte. Uma instalação pré-compilada fica em `~/.villagesql/` e inicia o servidor na porta 3306. Execute-o como um usuário comum: como root, ele encerra com `Error: Running this installer as root is not supported.`

Quando não há terminal para responder às perguntas — um job de CI, um Dockerfile com um `USER` não root, um agente de IA — passe as respostas em variáveis de ambiente. Defina-as no lado `bash` do pipe:

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=mysql-8.4 INSTALL_METHOD=prebuilt bash
```

`VSQL_CODEBASE` aceita `mysql-8.4`, `percona-8.4` ou `mysql-9.7`. `INSTALL_METHOD` aceita `docker`, `prebuilt` ou `source`. Uma compilação a partir do código-fonte também precisa de `VSQL_VERSION=stable|nightly|latest`; instalações via Docker e binário pré-compilado usam sempre a versão estável.

Para se conectar e instalar a sua primeira extensão, consulte [Instalar](/pt-BR/8.4/stable/install-server#step-2-connect-to-the-server).

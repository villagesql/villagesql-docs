## Instalar com o script de instalação

```bash
curl -fsSL https://install.villagesql.com | bash
```

O script pergunta qual base de código instalar (MySQL 8.4, Percona Server 8.4 ou MySQL 9.7) e como instalá-la: um download pré-compilado, Docker ou uma compilação a partir do código-fonte. Uma instalação pré-compilada fica em `~/.villagesql/` e inicia o servidor na porta 3306.

Para se conectar e carregar a sua primeira extensão, consulte [Instalar](/pt-BR/8.4/stable/install-server#step-2-connect-to-the-server).

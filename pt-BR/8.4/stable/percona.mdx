O VillageSQL também é compilado sobre o **Percona Server**, um fork do MySQL
compatível em nível de código-fonte que acrescenta seus próprios recursos de
armazenamento, desempenho e observabilidade.

## O que é isto {#what-this-is}

Um servidor VillageSQL compilado com a base de código do Percona 8.4 em vez do
MySQL 8.4 upstream. O VillageSQL Extension Framework, seus comandos SQL e suas
extensões funcionam da mesma maneira nas duas — uma compilação Percona é uma
fundação diferente sob a mesma superfície do VillageSQL.

O VillageSQL não documenta os recursos do próprio Percona. Para qualquer
assunto sobre o Percona Server em si — seus mecanismos de armazenamento,
opções de ajuste ou configuração — consulte a
[documentação do próprio Percona](https://docs.percona.com/percona-server/8.4/).

## O que não está incluído {#what-is-not-included}

Esta compilação deixa de fora três recursos do Percona.

**MyRocks.** O mecanismo de armazenamento RocksDB não é compilado, então
`SHOW ENGINES` não lista `ROCKSDB` e nenhuma variável de sistema `rocksdb_*`
existe. Uma tabela que pede esse mecanismo falha:

```sql
CREATE TABLE t (i INT) ENGINE=ROCKSDB;
-- ERROR 1286 (42000): Unknown storage engine 'ROCKSDB'
```

Restaurar um dump de um servidor Percona para na primeira tabela que nomeia o
mecanismo, então as tabelas criadas antes desse ponto permanecem e as demais
são ignoradas.

**O componente de keyring KMIP.** `component_keyring_file`,
`component_keyring_kms` e `component_keyring_vault` são todos entregues e
podem ser instalados. `component_keyring_kmip` não é compilado, e instalá-lo
falha com `ERROR 1126`.

**O coredumper do Percona.** A opção `--coredumper` continua sendo aceita,
porque o servidor a registra independentemente de a biblioteca ter sido
compilada, e aqui a biblioteca não é compilada.

As outras adições do Percona funcionam normalmente, incluindo o componente
`percona_udf`, o plugin de log de auditoria e as visões `USER_STATISTICS` e
`TABLE_STATISTICS`, que são preenchidas depois de `SET GLOBAL userstat = ON`.

## Identificando uma compilação Percona {#identifying-a-percona-build}

Uma compilação Percona informa uma base de código diferente em sua string de
versão:

```sql
SELECT @@villagesql_server_version;
-- Example output: percona-8.4_0.0.7
```

Consulte [Referência do Sistema](/pt-BR/8.4/stable/reference#villagesql_server_version)
para saber o que essa variável significa. O VillageSQL se recusa a atualizar um
diretório de dados de uma base de código (por exemplo, `mysql-8.4`) em um
servidor que executa outra (por exemplo, `percona-8.4`).

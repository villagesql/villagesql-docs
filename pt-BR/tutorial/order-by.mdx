Uma tabela não tem ordem. As linhas voltam na ordem que o servidor achar
conveniente, e isso pode mudar de uma execução para a outra. `ORDER BY` é a
única coisa que decide a ordem de um resultado.

Abra o cliente com `mysql -u root -p sakila` antes de começar.

## Como o ORDER BY funciona {#how-order-by-works}

```sql
SELECT COLUMN_LIST
FROM TABLE_NAME
ORDER BY SORT_COLUMN DIRECTION;
```

Substitua `SORT_COLUMN` pela coluna pela qual ordenar. `DIRECTION` é `ASC`
para o menor primeiro ou `DESC` para o maior primeiro. É opcional, e deixá-lo
de fora significa `ASC`.

## Exemplos {#examples}

### 1) Ordenar por uma coluna {#1-sort-by-one-column}

```sql
SELECT title FROM film ORDER BY title;
```

```text
+-----------------------------+
| title                       |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
| AFFAIR PREJUDICE            |
| AFRICAN EGG                 |
...
+-----------------------------+
1000 rows in set (0.01 sec)
```

### 2) Ordenar no sentido contrário {#2-sort-the-other-way}

```sql
SELECT title, rental_rate FROM film ORDER BY rental_rate DESC;
```

```text
+-----------------------------+-------------+
| title                       | rental_rate |
+-----------------------------+-------------+
| ACE GOLDFINGER              |        4.99 |
| AIRPLANE SIERRA             |        4.99 |
| AIRPORT POLLOCK             |        4.99 |
| ALADDIN CALENDAR            |        4.99 |
| ALI FOREVER                 |        4.99 |
...
+-----------------------------+-------------+
1000 rows in set (0.00 sec)
```

O Sakila precifica todo filme em 1 de apenas 3 valores, e 336 filmes compartilham o valor mais alto,
de 4.99. A ordem entre essas 336 linhas empatadas não é decidida por esta consulta, então
ela pode diferir da ordem que você vê aqui.

### 3) Desempatar com uma segunda coluna {#3-break-the-tie-with-a-second-column}

Liste as colunas de ordenação em ordem de prioridade, separadas por vírgulas. Cada uma recebe sua
própria direção.

```sql
SELECT title, rental_rate, length
FROM film
ORDER BY rental_rate DESC, length;
```

```text
+-----------------------------+-------------+--------+
| title                       | rental_rate | length |
+-----------------------------+-------------+--------+
| IRON MOON                   |        4.99 |     46 |
| HANOVER GALAXY              |        4.99 |     47 |
| ACE GOLDFINGER              |        4.99 |     48 |
| MIDSUMMER GROUNDHOG         |        4.99 |     48 |
| PELICAN COMFORTS            |        4.99 |     48 |
...
+-----------------------------+-------------+--------+
1000 rows in set (0.00 sec)
```

`rental_rate` ainda manda, em ordem decrescente. Dentro de cada valor o filme mais curto vem
primeiro. Filmes de mesma duração continuam empatados, então uma ordem totalmente decidida precisa de
colunas suficientes para tornar cada linha única.

### 4) Ordenar por um alias {#4-sort-by-an-alias}

`ORDER BY` pode nomear um alias de coluna da mesma consulta.

```sql
SELECT title AS film_title FROM film ORDER BY film_title;
```

```text
+-----------------------------+
| film_title                  |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
...
+-----------------------------+
1000 rows in set (0.00 sec)
```

## Coloque um alias entre crases, não entre aspas simples {#quote-an-alias-with-backticks-not-single-quotes}

Um alias que contém um espaço tem de ser delimitado, e aqui os 2 estilos de delimitação deixam
de concordar. Aspas simples fazem uma string em vez de um nome, e ordenar por uma
string fixa não ordena nada.

```sql
SELECT title, rental_rate AS 'Rate' FROM film ORDER BY 'Rate';
```

```text
+-----------------------------+------+
| title                       | Rate |
+-----------------------------+------+
| ACADEMY DINOSAUR            | 0.99 |
| ACE GOLDFINGER              | 4.99 |
| ADAPTATION HOLES            | 2.99 |
| AFFAIR PREJUDICE            | 2.99 |
| AFRICAN EGG                 | 2.99 |
...
+-----------------------------+------+
1000 rows in set (0.00 sec)
```

Os valores vêm na ordem 0.99, 4.99, 2.99, então nada foi ordenado. O servidor leu `'Rate'`
como a palavra de 4 letras e ordenou cada linha pelo mesmo valor. Nenhum erro, nenhum
aviso, nenhuma ordenação.

As crases nomeiam o alias, e a ordenação acontece:

```sql
SELECT title, rental_rate AS `Rate` FROM film ORDER BY `Rate`;
```

```text
+-----------------------------+------+
| title                       | Rate |
+-----------------------------+------+
| ACADEMY DINOSAUR            | 0.99 |
| ALAMO VIDEOTAPE             | 0.99 |
| ALASKA PHANTOM              | 0.99 |
| ALICE FANTASIA              | 0.99 |
| ALONE TRIP                  | 0.99 |
...
+-----------------------------+------+
1000 rows in set (0.00 sec)
```

Todas as linhas mostradas estão em 0.99, então a ordem delas entre si também não é decidida
aqui.

## Onde o NULL cai {#where-null-lands}

Uma coluna pode conter `NULL`, que registra que não há nenhum valor ali. Não é
um zero e não é uma string vazia. O MySQL ordena `NULL` abaixo de todo valor real,
então a ordem crescente coloca os NULLs primeiro. Das 603 linhas em `address`, 4 não
têm `address2`.

```sql
SELECT address_id, address2 FROM address ORDER BY address2;
```

```text
+------------+----------+
| address_id | address2 |
+------------+----------+
|          1 | NULL     |
|          2 | NULL     |
|          3 | NULL     |
|          4 | NULL     |
|        303 |          |
|        605 |          |
...
+------------+----------+
603 rows in set (0.00 sec)
```

As 4 linhas NULL vêm primeiro. As linhas depois delas contêm uma string vazia, que é
um valor real, então ela fica acima de `NULL` e abaixo de qualquer texto. Essas 4 linhas NULL
estão empatadas entre si, então a ordem entre elas não é decidida por esta consulta.

`DESC` inverte isso e os NULLs vão para o final. Este é o fim do mesmo
resultado ordenado no sentido contrário:

```sql
SELECT address_id, address2 FROM address ORDER BY address2 DESC;
```

```text
+------------+----------+
| address_id | address2 |
+------------+----------+
...
|        532 |          |
|          1 | NULL     |
|          2 | NULL     |
|          3 | NULL     |
|          4 | NULL     |
+------------+----------+
603 rows in set (0.00 sec)
```

## Resumo {#summary}

- Use `ORDER BY` para decidir a ordem de um resultado, porque nada mais decide.
- Escreva `DESC` para o maior primeiro; `ASC` é o padrão.
- Liste várias colunas de ordenação, em ordem de prioridade, para desempatar.
- Coloque um alias entre crases ao ordenar por ele, porque aspas simples fazem uma string.
- Espere `NULL` primeiro ao ordenar em ordem crescente, e por último ao ordenar em ordem decrescente.

`LIMIT` limita quantas linhas uma consulta retorna. É o que você usa para olhar
o topo de uma tabela grande, e é o mecanismo por trás da paginação de
resultados.

Abra o cliente com `mysql -u root -p sakila` antes de começar.

## Como o LIMIT funciona {#how-limit-works}

```sql
SELECT COLUMN_LIST
FROM TABLE_NAME
ORDER BY SORT_COLUMN
LIMIT ROW_COUNT OFFSET SKIP_COUNT;
```

Substitua `ROW_COUNT` por quantas linhas você quer e `SKIP_COUNT` por quantas
pular primeiro. `LIMIT` vai por último, depois do `ORDER BY`. A parte `OFFSET` é
opcional.

## Exemplos {#examples}

### 1) As primeiras linhas {#1-the-first-few-rows}

```sql
SELECT title FROM film ORDER BY title LIMIT 5;
```

```text
+------------------+
| title            |
+------------------+
| ACADEMY DINOSAUR |
| ACE GOLDFINGER   |
| ADAPTATION HOLES |
| AFFAIR PREJUDICE |
| AFRICAN EGG      |
+------------------+
5 rows in set (0.00 sec)
```

O resultado inteiro são 5 linhas, então a borda de fechamento e a contagem são o fim
real dele, e não um corte.

### 2) Pular algumas linhas primeiro {#2-skip-some-rows-first}

```sql
SELECT title FROM film ORDER BY title LIMIT 5 OFFSET 10;
```

```text
+-----------------+
| title           |
+-----------------+
| ALAMO VIDEOTAPE |
| ALASKA PHANTOM  |
| ALI FOREVER     |
| ALICE FANTASIA  |
| ALIEN CENTER    |
+-----------------+
5 rows in set (0.00 sec)
```

Linhas 11 a 15 da lista ordenada.

### 3) A forma com 2 números {#3-the-2-number-form}

O MySQL também aceita o deslocamento e a contagem como um par separado por vírgula, deslocamento
primeiro. Significa exatamente a mesma coisa.

```sql
SELECT title FROM film ORDER BY title LIMIT 10, 5;
```

```text
+-----------------+
| title           |
+-----------------+
| ALAMO VIDEOTAPE |
| ALASKA PHANTOM  |
| ALI FOREVER     |
| ALICE FANTASIA  |
| ALIEN CENTER    |
+-----------------+
5 rows in set (0.00 sec)
```

Os mesmos 5 títulos do exemplo 2. Os 2 números aparecem na ordem oposta
entre as 2 formas, o que é uma fonte confiável de confusão de um a mais ou a menos, então
este tutorial escreve `LIMIT ROW_COUNT OFFSET SKIP_COUNT`.

## LIMIT sem ORDER BY pede linhas arbitrárias {#limit-without-order-by-asks-for-arbitrary-rows}

Tire o `ORDER BY` e a consulta ainda roda.

```sql
SELECT title FROM film LIMIT 5;
```

```text
+------------------+
| title            |
+------------------+
| ACADEMY DINOSAUR |
| ACE GOLDFINGER   |
| ADAPTATION HOLES |
| AFFAIR PREJUDICE |
| AFRICAN EGG      |
+------------------+
5 rows in set (0.00 sec)
```

Esses são os mesmos 5 títulos que a consulta ordenada retornou, e é isso que torna
isto perigoso. Nada na instrução os pediu nessa ordem. Pergunte ao
servidor como ele rodou a consulta e ele diz por que eles voltaram desse jeito:

```sql
EXPLAIN SELECT title FROM film LIMIT 5;
```

```text
+----+-------------+-------+------------+-------+---------------+-----------+---------+------+------+----------+-------------+
| id | select_type | table | partitions | type  | possible_keys | key       | key_len | ref  | rows | filtered | Extra       |
+----+-------------+-------+------------+-------+---------------+-----------+---------+------+------+----------+-------------+
|  1 | SIMPLE      | film  | NULL       | index | NULL          | idx_title | 514     | NULL | 1000 |   100.00 | Using index |
+----+-------------+-------+------------+-------+---------------+-----------+---------+------+------+----------+-------------+
1 row in set, 1 warning (0.00 sec)
```

Não é preciso ir atrás desse `1 warning`. `EXPLAIN` e `EXPLAIN FORMAT=JSON`
anexam a `Note 1003`, que contém a consulta como o otimizador a reescreveu, e
`SHOW WARNINGS` a imprime.

A coluna `key` nomeia `idx_title`, um índice em `title` que já mantém a
coluna em ordem, então ler o índice é o jeito mais barato de responder. As
linhas chegaram ordenadas como efeito colateral dessa escolha. Remova esse índice, adicione
outra coluna à lista de seleção, ou dê ao servidor mais dados, e a escolha
pode mudar sem nenhuma mudança na sua consulta.

`LIMIT` significa "quaisquer linhas" a menos que o `ORDER BY` diga quais.

## Resumo {#summary}

- Use `LIMIT` para limitar quantas linhas voltam.
- Adicione `OFFSET` para pular linhas antes de pegá-las.
- Prefira `LIMIT ROW_COUNT OFFSET SKIP_COUNT` à forma com vírgula, que inverte os números.
- Combine `LIMIT` com `ORDER BY` sempre, ou você estará pedindo linhas arbitrárias.

Um alias de tabela é um nome curto para uma tabela, pela duração de 1 consulta. Ele economiza
digitação em um join, e uma consulta que nomeia a mesma tabela duas vezes não funciona
sem um.

Abra o cliente com `mysql -u root -p sakila` antes de começar.

## Como um alias de tabela funciona {#how-a-table-alias-works}

```sql
SELECT ALIAS_NAME.COLUMN_NAME
FROM TABLE_NAME AS ALIAS_NAME;
```

Substitua `TABLE_NAME` pela tabela, `ALIAS_NAME` pelo nome curto que você quer,
e `COLUMN_NAME` por uma coluna dessa tabela. A partir desse ponto, o alias
é o nome da tabela nesta consulta, e você escreve `ALIAS_NAME.COLUMN_NAME`
para nomear uma coluna dela.

`AS` é opcional aqui, como é com um alias de coluna, então `FROM film f` significa o
mesmo que `FROM film AS f`. Escrever `AS` deixa a intenção clara.

## O mesmo join, escrito das duas formas {#the-same-join-written-both-ways}

Sem aliases, toda coluna qualificada carrega o nome completo da tabela.

```sql
SELECT film.title, language.name
FROM film
JOIN language ON film.language_id = language.language_id
ORDER BY film.title
LIMIT 3;
```

```text
+------------------+---------+
| title            | name    |
+------------------+---------+
| ACADEMY DINOSAUR | English |
| ACE GOLDFINGER   | English |
| ADAPTATION HOLES | English |
+------------------+---------+
3 rows in set (0.00 sec)
```

Com aliases, a mesma consulta fica mais curta e a forma é mais fácil de ver.

```sql
SELECT f.title, l.name
FROM film AS f
JOIN language AS l ON f.language_id = l.language_id
ORDER BY f.title
LIMIT 3;
```

```text
+------------------+---------+
| title            | name    |
+------------------+---------+
| ACADEMY DINOSAUR | English |
| ACE GOLDFINGER   | English |
| ADAPTATION HOLES | English |
+------------------+---------+
3 rows in set (0.00 sec)
```

Linhas idênticas. Um alias não muda nada na resposta.

## Uma coluna que existe nas duas tabelas precisa ser qualificada {#a-column-that-exists-in-both-tables-has-to-be-qualified}

`film` e `language` têm, ambas, um `language_id`. Nomeá-lo sem qualificação não dá ao
servidor nenhuma forma de escolher.

```sql
SELECT language_id
FROM film
JOIN language ON film.language_id = language.language_id
LIMIT 1;
```

```text
ERROR 1052 (23000): Column 'language_id' in field list is ambiguous
```

`ERROR 1052` significa que o servidor encontrou mais de 1 coisa a que o nome poderia se referir.
Em um join, isso é quase sempre uma coluna que 2 tabelas compartilham, e qualificá-la com
a tabela ou o alias que você quis dizer resolve. Um nome de coluna que apenas 1 tabela tem não precisa
de qualificação, e é por isso que `title` e `name` funcionam sem qualificação nas consultas
acima.

## O alias substitui o nome da tabela {#the-alias-replaces-the-table-name}

Depois que uma tabela tem um alias, o nome original desaparece pelo resto da consulta.

```sql
SELECT film.title
FROM film AS f
JOIN language AS l ON f.language_id = l.language_id
LIMIT 1;
```

```text
ERROR 1054 (42S22): Unknown column 'film.title' in 'field list'
```

A tabela continua sendo `film` no banco de dados. Dentro desta consulta, ela atende por `f`
e por nada mais. `ERROR 1054` em um nome que você consegue ver no esquema normalmente é
isso.

## O caso que não pode ser escrito sem um alias {#the-case-that-cannot-be-written-without-an-alias}

Uma consulta que nomeia a mesma tabela duas vezes tem 2 coisas chamadas `actor` e nenhuma forma
de distingui-las. Os aliases são o que torna essa consulta possível, e a
lição sobre [Self join](/pt-BR/tutorial/self-join) é construída sobre isso.

## Um alias de tabela não é um alias de coluna {#a-table-alias-is-not-a-column-alias}

Eles usam a mesma palavra-chave e fazem trabalhos diferentes. Um alias de coluna renomeia uma
coluna do resultado e aparece no cabeçalho. Um alias de tabela renomeia uma tabela
dentro da consulta e nunca aparece na saída. Consulte
[Aliases de coluna](/pt-BR/tutorial/column-aliases) para o outro tipo.

## Resumo {#summary}

- Use `TABLE_NAME AS ALIAS_NAME` para dar a uma tabela um nome curto por 1 consulta.
- Qualifique qualquer nome de coluna que mais de 1 tabela da consulta tenha.
- Leia `ERROR 1052` em um join como um nome de coluna que você precisa qualificar.
- Suspeite de um alias esquecido quando `ERROR 1054` nomeia uma coluna que você sabe que existe.
- Espere que um alias não mude nada no resultado.

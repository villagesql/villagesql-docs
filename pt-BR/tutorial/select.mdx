`SELECT` lê linhas de uma tabela. Esta lição cobre sua menor forma
útil: nomeie uma tabela, nomeie algumas colunas, receba linhas de volta.

Todos os exemplos consultam o banco de dados Sakila. Se você ainda não o carregou,
[carregue o Sakila primeiro](/pt-BR/tutorial/load-sakila), depois abra o cliente com
`mysql -u root -p sakila` para que `sakila` seja o banco de dados atual.

## Como SELECT funciona {#how-select-works}

```sql
SELECT COLUMN_LIST
FROM TABLE_NAME;
```

`COLUMN_LIST` é o que você quer em cada linha, normalmente nomes de coluna separados por
vírgulas. `TABLE_NAME` é a tabela de onde as linhas vêm.

Uma instrução termina no ponto e vírgula. O cliente continua lendo até encontrar um,
então uma linha sem ponto e vírgula deixa você em um prompt de continuação:

```text
mysql> SELECT name FROM language
    -> ;
+----------+
| name     |
+----------+
| English  |
| Italian  |
| Japanese |
| Mandarin |
| French   |
| German   |
+----------+
6 rows in set (0.00 sec)
```

## Exemplos {#examples}

### 1) Selecione uma coluna {#1-select-one-column}

Peça à tabela `film` o título de cada filme e nada mais.

```sql
SELECT title FROM film;
```

```text
+-----------------------------+
| title                       |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
| AFFAIR PREJUDICE            |
| AFRICAN EGG                 |
...
+-----------------------------+
1000 rows in set (0.01 sec)
```

Uma linha volta para cada linha da tabela, 1.000 delas aqui. `SELECT`
não filtra nada por conta própria. Escolher quais linhas você recebe é o trabalho do
[WHERE](/pt-BR/tutorial/where).

### 2) Selecione várias colunas {#2-select-several-columns}

Separe os nomes das colunas com vírgulas. Elas voltam na ordem em que você as
pediu, que não precisa ser a ordem em que estão na tabela.

```sql
SELECT title, release_year, rental_rate FROM film;
```

```text
+-----------------------------+--------------+-------------+
| title                       | release_year | rental_rate |
+-----------------------------+--------------+-------------+
| ACADEMY DINOSAUR            |         2006 |        0.99 |
| ACE GOLDFINGER              |         2006 |        4.99 |
| ADAPTATION HOLES            |         2006 |        2.99 |
| AFFAIR PREJUDICE            |         2006 |        2.99 |
| AFRICAN EGG                 |         2006 |        2.99 |
...
+-----------------------------+--------------+-------------+
1000 rows in set (0.00 sec)
```

### 3) Selecione todas as colunas {#3-select-every-column}

Um asterisco representa todas as colunas da tabela. A tabela `language` tem 6
linhas, então esta consulta imprime um resultado completo.

```sql
SELECT * FROM language;
```

```text
+-------------+----------+---------------------+
| language_id | name     | last_update         |
+-------------+----------+---------------------+
|           1 | English  | 2006-02-15 05:02:19 |
|           2 | Italian  | 2006-02-15 05:02:19 |
|           3 | Japanese | 2006-02-15 05:02:19 |
|           4 | Mandarin | 2006-02-15 05:02:19 |
|           5 | French   | 2006-02-15 05:02:19 |
|           6 | German   | 2006-02-15 05:02:19 |
+-------------+----------+---------------------+
6 rows in set (0.00 sec)
```

`SELECT *` tem seu lugar enquanto você explora uma tabela que não conhece.
Dentro do código de uma aplicação, nomeie suas colunas. Um asterisco envia todas as colunas pela
rede, quer o código as leia ou não, e muda de forma por baixo do
código no dia em que alguém adiciona uma coluna.

### 4) Calcule um valor {#4-compute-a-value}

A lista de seleção não precisa nomear uma coluna. Coloque uma expressão nela e o
resultado se torna uma coluna própria.

```sql
SELECT title, rental_rate, rental_rate * 1.1 FROM film;
```

```text
+-----------------------------+-------------+-------------------+
| title                       | rental_rate | rental_rate * 1.1 |
+-----------------------------+-------------+-------------------+
| ACADEMY DINOSAUR            |        0.99 |             1.089 |
| ACE GOLDFINGER              |        4.99 |             5.489 |
| ADAPTATION HOLES            |        2.99 |             3.289 |
| AFFAIR PREJUDICE            |        2.99 |             3.289 |
| AFRICAN EGG                 |        2.99 |             3.289 |
...
+-----------------------------+-------------+-------------------+
1000 rows in set (0.00 sec)
```

O cabeçalho dessa terceira coluna é a expressão que você digitou, o que é preciso
e feio. Um [alias de coluna](/pt-BR/tutorial/column-aliases) dá a ela um nome escolhido por você.

## 2 coisas que pegam as pessoas de surpresa {#2-things-that-catch-people-out}

**As palavras-chave ignoram maiúsculas e minúsculas.** `SELECT`, `select` e `SeLeCt` funcionam.

```sql
select title from film;
```

```text
+-----------------------------+
| title                       |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
...
+-----------------------------+
1000 rows in set (0.00 sec)
```

Este tutorial escreve as palavras-chave em maiúsculas e todo o resto em minúsculas,
por convenção. Ela existe para que a forma de uma consulta longa seja lida de relance.

**Uma coluna com o nome errado gera um erro.** O MySQL não adivinha o que você quis dizer,
e não devolve um resultado vazio.

```sql
SELECT titel FROM film;
```

```text
ERROR 1054 (42S22): Unknown column 'titel' in 'field list'
```

`field list` é o nome que o servidor dá à lista de seleção, então essa mensagem localiza
o erro além de nomeá-lo. O mesmo erro termina de forma diferente quando o nome
errado está em outra parte da instrução, então leia o final da mensagem antes de sair
procurando.

## Resumo {#summary}

- Use `SELECT` com uma lista de colunas e `FROM` com uma tabela para ler linhas.
- Liste as colunas na ordem em que você as quer de volta.
- Recorra a `SELECT *` enquanto explora, e nomeie suas colunas no código de uma aplicação.
- Coloque uma expressão na lista de seleção para calcular um valor por linha.
- Espere `ERROR 1054` quando o nome de uma coluna estiver errado.

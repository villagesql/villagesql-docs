Você precisa de um servidor em execução e de um cliente que consiga falar com ele. Qualquer servidor MySQL 8.4 ou
mais recente funciona, e o VillageSQL também, que é o MySQL com um framework de extensões
adicionado. Nenhuma lição aqui usa uma extensão, então qualquer um dos dois serve.

## Escolha uma forma de rodar um servidor {#pick-a-way-to-run-a-server}

| Forma | Serve para | Onde ir |
|---|---|---|
| Docker | Experimentar e depois descartar | [MySQL no Docker](/pt-BR/guides/mysql-on-docker) |
| O instalador do VillageSQL | Um servidor que você mantém na sua própria máquina | [Instalar](/pt-BR/8.4/stable/install-server) |
| Um servidor que você já roda | Qualquer pessoa com MySQL 8.4 ou mais recente instalado | Nada a fazer |

Cada uma dessas páginas termina com um servidor em execução. Volte aqui quando tiver
um.

## Obtenha um cliente {#get-a-client}

Este tutorial comanda o servidor com `mysql`, o cliente de linha de comando. De onde ele
vem depende da forma que você escolheu:

- **O instalador.** O instalador coloca um cliente em `~/.villagesql/`, mas não
  no seu `PATH`. Rode o comando `Connect` salvo em
  `~/.villagesql/credentials.txt` (a senha de root está no mesmo arquivo), depois
  rode `SELECT VERSION();` no prompt `mysql>` em vez do comando abaixo.
- **Um servidor existente.** O cliente veio com o servidor, então você já o
  tem.
- **Docker.** O cliente mora dentro do contêiner, não na sua máquina. Alcance-o
  com `docker exec -it CONTAINER_NAME mysql -u root -p`, ou instale um cliente
  localmente e conecte pela porta que o contêiner publica.

## Verifique que você consegue conectar {#check-that-you-can-connect}

Rode isto, e pressione Return no prompt de senha se `root` não tiver senha:

```bash
mysql -u root -p -e "SELECT VERSION();"
```

```text
Enter password:
+-----------------------------------------+
| VERSION()                               |
+-----------------------------------------+
| 8.4.11-villagesql-0.0.7-dev-c857bdf32ce |
+-----------------------------------------+
```

A sua string de versão vai ser diferente. O que importa é que uma versão voltou,
porque isso significa que o cliente alcançou o servidor e fez login.

## Quando não conecta {#when-it-does-not-connect}

Os dois erros abaixo significam que o cliente nunca alcançou um servidor, então nenhum deles é
sobre a sua senha. Você pode reproduzir qualquer um dos dois em uma configuração que funciona
apontando o cliente para um lugar errado.

Um caminho de socket sem nada por trás:

```bash
mysql -S /tmp/mysql.sock.missing -u root -p -e "SELECT VERSION();"
```

```text
Enter password:
ERROR 2002 (HY000): Can't connect to local MySQL server through socket '/tmp/mysql.sock.missing' (2)
```

Uma porta sem nada escutando nela:

```bash
mysql -h 127.0.0.1 -P 3999 -u root -p -e "SELECT VERSION();"
```

```text
Enter password:
ERROR 2003 (HY000): Can't connect to MySQL server on '127.0.0.1:3999' (61)
```

O número entre os parênteses finais é o número de erro do próprio sistema operacional,
então ele pode diferir entre macOS e Linux. O número de socket ausente é 2 nos
dois; o número de conexão recusada é 61 no macOS e 111 no Linux. A parte a ler é o caminho do socket ou
o host e a porta, porque isso diz onde o cliente procurou. Se esse
lugar estiver errado, corrija-o. Se estiver certo, o servidor não está em execução.

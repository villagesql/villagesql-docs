Uma subconsulta é uma consulta dentro de outra consulta. Ela permite que você use uma resposta que ainda
não conhece: o filme mais longo, a classificação média, o conjunto de ids que corresponde a
alguma coisa. Sem ela, você executaria 2 consultas e colaria o primeiro resultado na
segunda à mão.

Abra o cliente com `mysql -u root -p sakila` antes de começar.

## Como uma subconsulta funciona {#how-a-subquery-works}

```sql
SELECT COLUMN_LIST
FROM TABLE_NAME
WHERE COLUMN_NAME = (SELECT AGGREGATE_FUNCTION(COLUMN_NAME) FROM TABLE_NAME);
```

Substitua `COLUMN_LIST` pelas colunas que você quer, `TABLE_NAME` pela tabela,
`COLUMN_NAME` pela coluna a testar, e `AGGREGATE_FUNCTION` pela
função que produz o valor com que você está comparando.

O servidor executa a subconsulta, pega o resultado dela e o usa na consulta externa.

Uma subconsulta entre parênteses que retorna exatamente 1 linha e 1 coluna é uma subconsulta
escalar, e ela se comporta como um valor. Essa é a forma mostrada abaixo, e a forma
que dá errado com mais frequência.

## Exemplos {#examples}

### 1) Use um valor que você não consegue escrever {#1-use-a-value-you-cannot-write-down}

Você não sabe a duração do filme mais longo, então peça por ela ali mesmo.

```sql
SELECT title, length
FROM film
WHERE length = (SELECT MAX(length) FROM film)
ORDER BY title;
```

```text
+--------------------+--------+
| title              | length |
+--------------------+--------+
| CHICAGO NORTH      |    185 |
| CONTROL ANTHEM     |    185 |
| DARN FORRESTER     |    185 |
...
+--------------------+--------+
10 rows in set (0.00 sec)
```

`MAX(length)` sozinho daria 185 e nada mais. A subconsulta leva esse valor
de volta a um `WHERE`, para que você receba os filmes também.

### 2) Uma subconsulta na lista de seleção {#2-a-subquery-in-the-select-list}

O mesmo valor pode ir na lista de seleção, onde ele se repete em todas as linhas.

```sql
SELECT title, length, (SELECT AVG(length) FROM film) AS catalog_mean
FROM film
ORDER BY title
LIMIT 3;
```

```text
+------------------+--------+--------------+
| title            | length | catalog_mean |
+------------------+--------+--------------+
| ACADEMY DINOSAUR |     86 |     115.2720 |
| ACE GOLDFINGER   |     48 |     115.2720 |
| ADAPTATION HOLES |     50 |     115.2720 |
+------------------+--------+--------------+
3 rows in set (0.00 sec)
```

A subconsulta é executada uma vez e sua resposta é copiada coluna abaixo, que é como
você mostra um valor ao lado das linhas que está comparando com ele.

### 3) Uma subconsulta que retorna uma lista {#3-a-subquery-that-returns-a-list}

Uma subconsulta que alimenta [IN](/pt-BR/tutorial/in) pode retornar muitas linhas, porque
`IN` espera uma lista, e não um valor.

```sql
SELECT first_name, last_name
FROM actor
WHERE actor_id IN (SELECT actor_id FROM film_actor WHERE film_id = 1)
ORDER BY last_name
LIMIT 5;
```

```text
+------------+-----------+
| first_name | last_name |
+------------+-----------+
| JOHNNY     | CAGE      |
| ROCK       | DUKAKIS   |
| CHRISTIAN  | GABLE     |
| PENELOPE   | GUINESS   |
| MARY       | KEITEL    |
+------------+-----------+
5 rows in set (0.00 sec)
```

A consulta interna retorna os ids de todos que estão no filme 1, e `IN` testa cada
ator contra essa lista inteira.

## ERROR 1242 significa que a subconsulta retornou linhas demais {#error-1242-means-the-subquery-returned-too-many-rows}

`=` compara 1 coisa com 1 coisa. Dê a ele uma subconsulta que retorna 1.000 linhas e
o servidor não consegue continuar.

```sql
SELECT title FROM film WHERE length = (SELECT length FROM film);
```

```text
ERROR 1242 (21000): Subquery returns more than 1 row
```

3 saídas, dependendo do que você quis dizer:

- Use `IN` em vez de `=`, quando uma lista era o que você queria.
- Adicione um agregado como `MAX()`, quando você queria 1 valor do conjunto.
- Adicione `LIMIT 1`, quando 1 linha qualquer serve e você consegue dizer qual com `ORDER BY`.

`ERROR 1242` pelo menos falha de forma ruidosa. A versão desse erro que não faz isso
é uma subconsulta que não retorna nenhuma linha: isso dá NULL, a comparação dá
NULL, e a consulta externa silenciosamente não retorna nada.

## Resumo {#summary}

- Use uma subconsulta para levar a resposta de uma consulta para dentro de outra.
- Espere que uma subconsulta escalar, 1 linha e 1 coluna, se comporte como um valor.
- Leia `ERROR 1242` como `=` contra uma subconsulta que retornou muitas linhas.
- Use `IN` em vez de `=` quando a subconsulta retorna uma lista.
- Suspeite de uma subconsulta vazia quando uma consulta externa não retorna nada e nenhum erro.

Todas as consultas até agora retornaram linhas. Uma função de agregação lê muitas linhas e
retorna 1 valor: quantas, o total, a média, a maior. É a primeira
coisa que você usa quando a pergunta é sobre um conjunto, e não sobre uma linha.

Abra o cliente com `mysql -u root -p sakila` antes de começar.

## Como uma função de agregação funciona {#how-an-aggregate-function-works}

```sql
SELECT AGGREGATE_FUNCTION(COLUMN_NAME)
FROM TABLE_NAME;
```

Substitua `AGGREGATE_FUNCTION` por uma das funções abaixo, `COLUMN_NAME`
pela coluna a ler, e `TABLE_NAME` pela tabela.

| Função | Retorna |
|---|---|
| `COUNT(*)` | quantas linhas existem, NULLs incluídos |
| `COUNT(column)` | quantas linhas têm um valor nessa coluna |
| `SUM(column)` | o total |
| `AVG(column)` | a média |
| `MIN(column)` | o menor valor |
| `MAX(column)` | o maior valor |

Sem `GROUP BY`, a tabela inteira é 1 grupo, então o resultado é sempre exatamente
1 linha. [GROUP BY](/pt-BR/tutorial/group-by) é como você obtém 1 linha por categoria
em vez disso.

## Exemplos {#examples}

### 1) Contar as linhas {#1-count-the-rows}

```sql
SELECT COUNT(*) AS films FROM film;
```

```text
+-------+
| films |
+-------+
|  1000 |
+-------+
1 row in set (0.00 sec)
```

1 linha, seja o que for que a tabela contenha. Uma agregação sempre responde.

### 2) Várias agregações de uma vez {#2-several-aggregates-at-once}

```sql
SELECT MIN(length) AS shortest, MAX(length) AS longest, AVG(length) AS mean
FROM film;
```

```text
+----------+---------+----------+
| shortest | longest | mean     |
+----------+---------+----------+
|       46 |     185 | 115.2720 |
+----------+---------+----------+
1 row in set (0.00 sec)
```

Cada uma lê as mesmas 1.000 linhas. Dê nomes a elas com
[aliases](/pt-BR/tutorial/column-aliases), porque o cabeçalho padrão é a expressão
inteira.

### 3) Totalizar uma coluna de dinheiro {#3-total-a-money-column}

```sql
SELECT SUM(amount) AS takings, COUNT(*) AS payments FROM payment;
```

```text
+----------+----------+
| takings  | payments |
+----------+----------+
| 67406.56 |    16044 |
+----------+----------+
1 row in set (0.00 sec)
```

## COUNT(*) e COUNT(coluna) são perguntas diferentes {#count-and-countcolumn-are-different-questions}

`COUNT(*)` conta linhas. `COUNT(column)` conta as linhas em que essa coluna contém
um valor, então ele ignora NULL.

```sql
SELECT COUNT(*) AS rows_total, COUNT(address2) AS with_a_value
FROM address;
```

```text
+------------+--------------+
| rows_total | with_a_value |
+------------+--------------+
|        603 |          599 |
+------------+--------------+
1 row in set (0.00 sec)
```

603 endereços, e 4 deles não têm segunda linha nenhuma. Os outros 599 contêm uma
string vazia, que o `COUNT` trata como um valor como qualquer outro: ele procura
NULL, não vazio. A lição [IS NULL](/pt-BR/tutorial/is-null) cobre essa
diferença.

## Toda agregação ignora NULL {#every-aggregate-skips-null}

A regra não é exclusiva do `COUNT`. Nenhuma agregação olha para um NULL, o que significa que uma
coluna sem nada dentro não produz nada para calcular a média. Calcular a média de um id é
aritmética sem sentido, e esta consulta faz isso só porque
`original_language_id` é a única coluna do Sakila que é NULL em todas as linhas.

```sql
SELECT COUNT(*) AS films,
       COUNT(original_language_id) AS with_a_value,
       AVG(original_language_id) AS mean
FROM film;
```

```text
+-------+--------------+------+
| films | with_a_value | mean |
+-------+--------------+------+
|  1000 |            0 | NULL |
+-------+--------------+------+
1 row in set (0.00 sec)
```

`AVG` retornou NULL em vez de 0, porque não havia nada para dividir. Isso
importa mais para `AVG` em uma coluna que só às vezes está preenchida: a média
é sobre as linhas que têm um valor, não sobre todas as linhas, e os 2 números
não são iguais. `SUM` de nada também é NULL, enquanto `COUNT` de nada é 0.

## Resumo {#summary}

- Use uma agregação para reduzir muitas linhas a 1 valor.
- Espere exatamente 1 linha de volta quando não há `GROUP BY`.
- Leia `COUNT(*)` como quantas linhas e `COUNT(column)` como quantas têm um valor.
- Espere que toda agregação ignore NULL, então uma média é sobre as linhas que têm um valor.
- Espere NULL em vez de 0 de `SUM` e `AVG` quando nada se qualifica.

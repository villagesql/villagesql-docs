O Sakila chega como 2 arquivos SQL em 1 zip. O primeiro constrói as tabelas, o
segundo as preenche. Você os roda nessa ordem, contra o servidor de
[Instale um servidor](/pt-BR/tutorial/install-mysql).

## Baixe {#download-it}

Rode estes em qualquer diretório que você quiser.

```bash
curl -O https://downloads.mysql.com/docs/sakila-db.zip
unzip sakila-db.zip
```

Isso deixa um diretório `sakila-db`. Os 2 arquivos dele de que você precisa são
`sakila-schema.sql` e `sakila-data.sql`.

## Carregue {#load-it}

O arquivo de esquema primeiro, depois o arquivo de dados. Pressione Return em cada prompt de senha
se `root` não tiver senha.

```bash
mysql -u root -p < sakila-db/sakila-schema.sql
mysql -u root -p < sakila-db/sakila-data.sql
```

Nenhum dos comandos imprime nada depois do prompt de senha quando funciona. O
arquivo de dados demora mais, porque insere todas as linhas do banco de dados.

<Note>
A primeira coisa que o arquivo de esquema faz é `DROP SCHEMA IF EXISTS sakila`. Rodar
esses 2 comandos de novo reconstrói o banco de dados do zero, então você sempre pode
voltar a uma cópia limpa. Tudo que você mudou vai embora junto.
</Note>

## Verifique {#check-it}

Pergunte ao servidor o que o banco de dados contém agora.

```bash
mysql -u root -p -e "USE sakila; SHOW TABLES;"
```

As tabelas podem chegar sem os dados, então conte alguma coisa também.

```bash
mysql -u root -p -e "SELECT COUNT(*) FROM sakila.film;"
```

```text

+----------+

```

1.000 filmes significa que você está pronto para a primeira lição.

## Trabalhe dentro do banco de dados {#work-inside-the-database}

Toda lição escreve suas consultas como se `sakila` fosse o banco de dados atual.
Informe o nome dele quando abrir o cliente:

```bash
mysql -u root -p sakila
```

Ou mude para ele quando já estiver dentro:

```sql
USE sakila;
```

Sem um desses, uma consulta que nomeia `film` falha.

```bash
mysql -u root -p -e "SELECT COUNT(*) FROM film;"
```

```text
Enter password:
ERROR 1046 (3D000) at line 1: No database selected
```

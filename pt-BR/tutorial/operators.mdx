Operadores combinam valores em um novo valor. Você já usou um: o `*`
em `rental_rate * 1.1`. Esta lição cobre o conjunto do dia a dia, e o único
comportamento que pega todo mundo, que é o que acontece quando `NULL` aparece.

Abra o cliente com `mysql -u root -p sakila` antes de começar.

## Como um operador funciona {#how-an-operator-works}

```sql
SELECT LEFT_VALUE OPERATOR RIGHT_VALUE;
```

Substitua `LEFT_VALUE` e `RIGHT_VALUE` por valores e `OPERATOR` por um dos
símbolos abaixo. Um valor pode ser uma coluna, ou pode ser um literal, ou seja, um
número ou um trecho de texto escrito diretamente na instrução.

Um `SELECT` sem `FROM` avalia suas expressões e retorna uma única linha,
o que faz dele o jeito mais rápido de experimentar um operador.

## Exemplos {#examples}

### 1) Uma comparação retorna 1 ou 0 {#1-comparison-returns-1-or-0}

O MySQL não tem um tipo booleano distinto. Uma comparação que vale retorna o inteiro
`1`, e uma que não vale retorna `0`. As palavras `TRUE` e `FALSE` são
grafias desses 2 inteiros.

```sql
SELECT 1 = 1, 1 <> 2, 1 != 2, 2 > 3, 3 >= 3, 2 <= 2;
```

```text
+-------+--------+--------+-------+--------+--------+
| 1 = 1 | 1 <> 2 | 1 != 2 | 2 > 3 | 3 >= 3 | 2 <= 2 |
+-------+--------+--------+-------+--------+--------+
|     1 |      1 |      1 |     0 |      1 |      1 |
+-------+--------+--------+-------+--------+--------+
1 row in set (0.00 sec)
```

Igualdade é um único `=`, não o `==` duplo que a maioria das linguagens de programação
usa. `<>` e `!=` significam ambos diferente e se comportam de forma idêntica. Este tutorial
escreve `<>`.

### 2) Aritmética, e qual operador tem precedência {#2-arithmetic-and-which-operator-binds-tighter}

```sql
SELECT 2 + 3 * 4, (2 + 3) * 4, 7 / 2, 7 DIV 2, 7 % 2;
```

```text
+-----------+-------------+--------+---------+-------+
| 2 + 3 * 4 | (2 + 3) * 4 | 7 / 2  | 7 DIV 2 | 7 % 2 |
+-----------+-------------+--------+---------+-------+
|        14 |          20 | 3.5000 |       3 |     1 |
+-----------+-------------+--------+---------+-------+
1 row in set (0.00 sec)
```

`2 + 3 * 4` é 14, então a multiplicação aconteceu primeiro. Os parênteses sobrepõem isso e
fazem dar 20. `/` dá um resultado decimal mesmo entre 2 números inteiros, `DIV`
joga a fração fora, e `%` dá o resto.

### 3) DIV e % têm a mesma precedência que a divisão {#3-div-and--bind-as-tightly-as-division}

```sql
SELECT 10 - 4 / 2, 10 - 4 DIV 2, 1 + 7 % 3;
```

```text
+------------+--------------+-----------+
| 10 - 4 / 2 | 10 - 4 DIV 2 | 1 + 7 % 3 |
+------------+--------------+-----------+
|     8.0000 |            8 |         2 |
+------------+--------------+-----------+
1 row in set (0.00 sec)
```

Os 3 dão a resposta que você obtém fazendo a divisão ou o resto primeiro. Se
`-` tivesse precedência maior que `/`, a primeira coluna seria 3 em vez de 8.

### 4) Operadores funcionam em colunas {#4-operators-work-on-columns}

Tudo que você pode fazer com um literal você pode fazer com uma coluna.

```sql
SELECT title, length, length > 100 AS is_long FROM film ORDER BY title;
```

```text
+-----------------------------+--------+---------+
| title                       | length | is_long |
+-----------------------------+--------+---------+
| ACADEMY DINOSAUR            |     86 |       0 |
| ACE GOLDFINGER              |     48 |       0 |
| ADAPTATION HOLES            |     50 |       0 |
| AFFAIR PREJUDICE            |    117 |       1 |
| AFRICAN EGG                 |    130 |       1 |
...
+-----------------------------+--------+---------+
1000 rows in set (0.00 sec)
```

A comparação vira uma coluna de 1s e 0s, e o alias dá um nome a ela.

## NULL não é igual a nada, nem mesmo a NULL {#null-is-not-equal-to-anything-including-null}

Você conheceu `NULL` na lição de ordenação como o marcador de um valor que nunca foi
registrado. Ele se comporta de forma diferente de qualquer valor real aqui.

```sql
SELECT NULL = NULL, NULL <> NULL, NULL <=> NULL, 1 <=> NULL;
```

```text
+-------------+--------------+---------------+------------+
| NULL = NULL | NULL <> NULL | NULL <=> NULL | 1 <=> NULL |
+-------------+--------------+---------------+------------+
|        NULL |         NULL |             1 |          0 |
+-------------+--------------+---------------+------------+
1 row in set (0.00 sec)
```

Perguntar se um valor não registrado é igual a outro não tem resposta, então
`NULL = NULL` retorna `NULL` em vez de 1 ou 0. `NULL <> NULL` também. Todo
operador do exemplo 1 se comporta assim com `NULL`.

`<=>` é a exceção. Ele compara 2 valores e sempre retorna 1 ou 0, nunca
`NULL`, tratando `NULL` como igual a si mesmo.

A consequência é que `= NULL` não corresponde a nada, nunca. Quando você precisa encontrar
as linhas em que um valor está ausente, [IS NULL](/pt-BR/tutorial/is-null) é o teste, e
ele retorna 1 ou 0 como uma comparação comum.

## Resumo {#summary}

- Espere `1` ou `0` de volta de uma comparação, não verdadeiro ou falso.
- Use `=` para igualdade e `<>` para diferença.
- Lembre-se de que `*`, `/`, `DIV` e `%` têm precedência maior que `+` e `-`.
- Use `DIV` para divisão inteira e `%` para o resto.
- Espere `NULL` de qualquer comparação comum que envolva `NULL`, e use `<=>` ou `IS NULL` em vez disso.

Este tutorial ensina SQL no MySQL em ordem, uma lição de cada vez. Toda lição
consulta o mesmo banco de dados de exemplo, então cada uma se apoia em dados que você já carregou
em vez de inventar tabelas novas. Todo resultado mostrado é uma saída capturada de um
servidor em execução, então você pode conferir sua tela com a página.

Leia-o em sequência se você é novo em SQL. Se você já escreve SQL e quer
uma resposta para uma pergunta, os guias de MySQL cobrem o mesmo
terreno organizado por tarefa, e não por lição.

## Onde o VillageSQL se encaixa {#where-villagesql-fits}

O VillageSQL é o MySQL com um framework de extensões adicionado, então toda instrução deste
tutorial é executada nele sem alteração. Nenhuma lição aqui precisa de uma extensão. Quando você
terminar, os guias cobrem o que as extensões adicionam por cima.

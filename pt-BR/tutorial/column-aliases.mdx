Um conjunto de resultados tira seus cabeçalhos de coluna do que você coloca na lista
do select. Para uma coluna simples, esse cabeçalho é o nome da coluna, o que normalmente
está bom. Para um cálculo, é a expressão que você digitou, o que não está. Um alias
substitui esse cabeçalho por um nome que você escolhe.

Abra o cliente com `mysql -u root -p sakila` antes de começar.

## Como um alias funciona {#how-an-alias-works}

```sql
SELECT COLUMN_OR_EXPRESSION AS ALIAS_NAME
FROM TABLE_NAME;
```

Substitua `COLUMN_OR_EXPRESSION` pela coluna ou pelo cálculo que você quer,
`ALIAS_NAME` pelo cabeçalho que você quer que ele tenha, e `TABLE_NAME` pela
tabela.

O alias se aplica apenas ao resultado. Nada na tabela muda, e a
próxima consulta não sabe nada sobre ele.

## Exemplos {#examples}

### 1) Renomear uma coluna {#1-rename-a-column}

```sql
SELECT title AS film_title FROM film;
```

```text
+-----------------------------+
| film_title                  |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
| AFFAIR PREJUDICE            |
| AFRICAN EGG                 |
...
+-----------------------------+
1000 rows in set (0.00 sec)
```

O cabeçalho diz `film_title`. Os valores ficam intocados.

### 2) Dar nome a um cálculo {#2-name-a-calculation}

É aqui que um alias ganha seu lugar. Sem um, o cabeçalho é a
aritmética.

```sql
SELECT title, rental_rate * 1.1 AS price_with_tax FROM film;
```

```text
+-----------------------------+----------------+
| title                       | price_with_tax |
+-----------------------------+----------------+
| ACADEMY DINOSAUR            |          1.089 |
| ACE GOLDFINGER              |          5.489 |
| ADAPTATION HOLES            |          3.289 |
| AFFAIR PREJUDICE            |          3.289 |
| AFRICAN EGG                 |          3.289 |
...
+-----------------------------+----------------+
1000 rows in set (0.00 sec)
```

O código da aplicação lê os resultados pelo nome da coluna, então uma expressão sem nome deixa
esse código dependente do texto exato da sua aritmética.

### 3) Um alias que contém um espaço {#3-an-alias-containing-a-space}

Um alias feito de letras, dígitos e sublinhados não precisa de aspas. Qualquer outra
coisa precisa, incluindo um espaço ou uma palavra que o MySQL reservou para uso próprio, como
`order` ou `select`. As crases são o estilo de aspas a usar.

```sql
SELECT title AS `Film Title` FROM film;
```

```text
+-----------------------------+
| Film Title                  |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
...
+-----------------------------+
1000 rows in set (0.00 sec)
```

As aspas simples produzem o mesmo cabeçalho:

```sql
SELECT title AS 'Film Title' FROM film;
```

```text
+-----------------------------+
| Film Title                  |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
...
+-----------------------------+
1000 rows in set (0.00 sec)
```

Elas não são equivalentes em todo lugar, porém. As crases marcam um nome, enquanto as aspas
simples marcam uma string, e uma cláusula posterior que se refere ao alias consegue notar
a diferença. A próxima lição mostra isso dando errado. Use crases e a
questão nunca aparece.

Deixe as aspas de fora por completo e o servidor para no espaço:

```sql
SELECT title AS Film Title FROM film;
```

```text
ERROR 1064 (42000): You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near 'Title FROM film' at line 1
```

`ERROR 1064` é o erro de sintaxe geral. O trecho entre aspas no fim da
mensagem é onde o servidor desistiu, o que normalmente fica uma ou duas palavras depois do
erro real.

## AS é opcional, e omiti-lo esconde um erro de digitação {#as-is-optional-and-leaving-it-out-hides-a-typo}

Um nome solto depois de uma coluna significa o mesmo que `AS`. É assim também que uma vírgula
esquecida se disfarça.

```sql
SELECT title release_year FROM film;
```

```text
+-----------------------------+
| release_year                |
+-----------------------------+
| ACADEMY DINOSAUR            |
| ACE GOLDFINGER              |
| ADAPTATION HOLES            |
...
+-----------------------------+
1000 rows in set (0.00 sec)
```

Isso era para ser 2 colunas. A vírgula ausente transformou `release_year` em um
alias de `title`, então o resultado tem 1 coluna, com o cabeçalho `release_year`, contendo
títulos de filmes. O servidor não reclamou de nada, porque a instrução é válida.

Escrever `AS` em todo alias não faz o servidor rejeitar isso, porque
nenhuma das colunas aqui tem um. Mas torna o erro visível quando você relê a
consulta: um nome solto depois de uma coluna, sem `AS` na frente, é uma
vírgula ausente.

## Resumo {#summary}

- Use `AS` para dar a uma coluna do resultado um nome escolhido por você.
- Sempre dê um alias a uma coluna calculada, porque o cabeçalho padrão dela é a expressão.
- Coloque um alias entre crases quando ele contém um espaço ou uma palavra reservada.
- Escreva `AS` em todo alias, para que um nome solto se leia como uma vírgula ausente.

`COUNT(*)` responde quantas linhas. `COUNT(DISTINCT column)` responde quantos
valores diferentes, que normalmente é a pergunta mais interessante sobre uma coluna
que você ainda não conhece.

Abra o cliente com `mysql -u root -p sakila` antes de começar.

## Como COUNT DISTINCT funciona {#how-count-distinct-works}

```sql
SELECT COUNT(DISTINCT COLUMN_NAME)
FROM TABLE_NAME;
```

Substitua `COLUMN_NAME` pela coluna cujos valores diferentes você quer contar,
e `TABLE_NAME` pela tabela. O servidor lê todas as linhas, descarta as
repetições, e conta o que sobra.

É a contagem das linhas não NULL que [SELECT DISTINCT](/pt-BR/tutorial/select-distinct) retornaria, sem retorná-las.

## Exemplos {#examples}

### 1) Quantos valores diferentes {#1-how-many-different-values}

```sql
SELECT COUNT(*) AS rows_total, COUNT(DISTINCT rating) AS ratings FROM film;
```

```text
+------------+---------+
| rows_total | ratings |
+------------+---------+
|       1000 |       5 |
+------------+---------+
1 row in set (0.01 sec)
```

1.000 filmes distribuídos em 5 classificações.

### 2) Combinações diferentes {#2-different-combinations}

Nomeie várias colunas e uma combinação conta uma vez, da mesma forma que o `GROUP BY`
as trata.

```sql
SELECT COUNT(DISTINCT rating, rental_rate) AS combinations FROM film;
```

```text
+--------------+
| combinations |
+--------------+
|           15 |
+--------------+
1 row in set (0.00 sec)
```

5 classificações vezes 3 tarifas, e toda combinação ocorre. Uma linha em que qualquer uma das
colunas nomeadas é NULL não é contada de jeito nenhum.

## Ele ignora NULL, o que pode fazer a resposta parecer errada {#it-skips-null-which-can-make-the-answer-look-wrong}

`address2` é NULL em 4 linhas e uma string vazia nas outras 599.

```sql
SELECT COUNT(*) AS rows_total,
       COUNT(DISTINCT address2) AS distinct_values
FROM address;
```

```text
+------------+-----------------+
| rows_total | distinct_values |
+------------+-----------------+
|        603 |               1 |
+------------+-----------------+
1 row in set (0.00 sec)
```

A resposta é 1. A string vazia é 1 valor distinto, e os NULLs são
ignorados em vez de contados como um valor próprio. Então "quantas coisas diferentes há
nesta coluna" não é o que a função responde quando algumas linhas estão vazias: ela
responde "quantos valores diferentes", e NULL é a ausência de um.

Quando você precisa dos dois números, conte as linhas ausentes com uma segunda consulta:
`SELECT COUNT(*) FROM address WHERE address2 IS NULL`.

## Resumo {#summary}

- Use `COUNT(DISTINCT column)` para contar valores diferentes em vez de linhas.
- Nomeie várias colunas para contar combinações distintas.
- Espere que NULL seja ignorado, e não contado como um valor.
- Conte as linhas ausentes separadamente quando precisar dos dois números.

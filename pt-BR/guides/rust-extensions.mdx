As extensões do VillageSQL podem ser escritas em Rust usando o crate `villagesql`. O SDK cuida de todo o marshaling de FFI — você escreve Rust comum, e a macro `extension!` gera os pontos de entrada em C que o servidor chama no momento do carregamento.

## Quando Escolher Rust {#when-to-choose-rust}

Rust é a escolha certa quando:

- Você prefere Rust e não precisa de uma base de código em C++
- Você quer segurança de memória sem um garbage collector
- Você está construindo uma nova extensão e não tem nenhuma dependência existente em C++

Se você tem uma base de código existente em C++ ou precisa da API de construção de tipos personalizados mais completa disponível hoje, consulte [Escrevendo Extensões em C++](/pt-BR/guides/cpp-extensions).

<Warning>
A API é estável para o desenvolvimento de extensões, mas a API de construção de tipos personalizados ainda está amadurecendo.
</Warning>

## Pré-requisitos {#prerequisites}

Você precisa de:

- **Toolchain estável do Rust** — instale em [rustup.rs](https://rustup.rs)
- **cargo-vsql** — o subcomando do Cargo para empacotar, instalar e testar

Instale o `cargo-vsql` a partir do repositório do SDK:

```bash
git clone https://github.com/villagesql/vsql-rust-sdk
cd vsql-rust-sdk
cargo install --path cargo-vsql
```

## Configure um Novo Crate {#set-up-a-new-crate}

Crie um crate de biblioteca, adicione o SDK e configure-o:

```bash
cargo new --lib vsql_my_extension
cd vsql_my_extension
cargo add villagesql
```

Em seguida, defina o tipo do crate em `Cargo.toml`:

```toml
[lib]
crate-type = ["cdylib"]
```

Adicione `manifest.json` ao lado de `Cargo.toml`:

```json
{
  "name": "vsql_my_extension",
  "version": "0.1.0",
  "description": "My VillageSQL extension",
  "author": "Your Name",
  "license": "GPL-2.0"
}
```

## Escreva uma Função {#write-a-function}

A página [Construindo Extensões em Rust](/pt-BR/extensions/build/rust-sdk) tem o passo a passo completo com o exemplo ROT-13. A versão resumida: implemente `fn(&[InValue]) -> VdfReturn`, registre-a com `func!` e envolva tudo em `extension!`:

```rust
use villagesql::{InValue, VdfReturn};

fn my_func_impl(args: &[InValue]) -> VdfReturn {
    match args.first() {
        Some(InValue::String(s)) => VdfReturn::string(s.to_uppercase()),
        Some(InValue::Null) | None => VdfReturn::null(),
        _ => VdfReturn::error("my_func: expected a STRING argument"),
    }
}

villagesql::extension! {
    funcs: [
        villagesql::func!(my_func_impl, "my_func", [villagesql::Type::String] -> villagesql::Type::String),
    ]
}
```

Para tipos personalizados (armazenamento binário, ordenação, hashing), consulte [Tipos Personalizados em Rust](/pt-BR/sdk/rust/custom-types).

## Teste Sua Extensão {#test-your-extension}

Escreva um teste em `mysql-test/t/basic.test`:

```sql
INSTALL EXTENSION vsql_my_extension;
SELECT my_func('hello');
SELECT my_func(NULL);
UNINSTALL EXTENSION vsql_my_extension;
```

Defina o diretório de build do seu VillageSQL, gere os resultados esperados e então execute:

```bash
export VillageSQL_BUILD_DIR=/path/to/villagesql/build
cargo vsql test --record
cargo vsql test
```

Uma execução bem-sucedida imprime `[ pass ]` para cada arquivo de teste.

## Instale em SQL {#install-in-sql}

Empacote e instale:

```bash
cargo vsql install
```

Em seguida, em SQL:

```sql
INSTALL EXTENSION vsql_my_extension;
SELECT * FROM INFORMATION_SCHEMA.EXTENSIONS WHERE EXTENSION_NAME = 'vsql_my_extension';
SELECT my_func('hello');
-- → HELLO
```

## O que é o VillageSQL Server?

O VillageSQL Server é um substituto direto para o MySQL com extensões para a era da IA agêntica. O seu framework de extensões permite que qualquer pessoa adicione tipos de dados personalizados e funções personalizadas ao servidor, sem pedir permissão e sem alterar o código do servidor.

## Extensões para o MySQL
Uma extensão adiciona recursos a um servidor VillageSQL em execução. As extensões podem adicionar:
- **Tipos de dados personalizados:** novos tipos para colunas InnoDB, como `UUID`, `COMPLEX` e `INET`, que você usa como os tipos nativos.
- **Funções personalizadas:** funções escritas em C++ ou Rust que você chama a partir do SQL.

Você adiciona e remove uma extensão com SQL: `INSTALL EXTENSION` e `UNINSTALL EXTENSION`.

Consulte o [catálogo de extensões](/pt-BR/extensions/catalog) para ver as extensões que você pode instalar.

### Crie uma Extensão
Comece pelo [template de extensão](https://github.com/villagesql/vsql-extension-template) e siga o [guia de C++](/en/guides/cpp-extensions) ou o [guia de Rust](/en/guides/rust-extensions). Para um fluxo de trabalho guiado e assistido por IA, experimente o [Extension Builder](https://villagesql.com/agent-skills).

## Por que o VillageSQL?

  <Card title="Compatibilidade Direta" icon="check-double">
    O VillageSQL fala o protocolo MySQL, então os seus clientes e drivers MySQL se conectam a ele.
  </Card>
  <Card title="Núcleo Extensível" icon="puzzle-piece">
    Adicione recursos a um servidor em execução com `INSTALL EXTENSION`. O servidor não precisa de reinicialização.
  </Card>
  <Card title="Ecossistema Aberto" icon="users">

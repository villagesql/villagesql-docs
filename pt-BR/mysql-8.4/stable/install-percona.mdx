A compilação Percona é publicada junto com a compilação MySQL 8.4. Instale-a com
o script de instalação, com o Docker ou com uma compilação a partir do código-fonte.

**Script de instalação, em um terminal.** Execute o script e, em seguida, escolha **2) Percona 8.4**
na primeira pergunta:

```bash
curl -fsSL https://install.villagesql.com | bash
```

**Script de instalação, sem terminal.** Em um job de CI, em um Dockerfile ou em um agente de IA,
indique a base de código e o método de instalação no lado `bash` do pipe:

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=percona-8.4 INSTALL_METHOD=prebuilt bash
```

**Docker.** As imagens são publicadas por base de código e por arquitetura:

```bash
docker run -d --name vsql -e MYSQL_ROOT_PASSWORD=<your-password> -p 3306:3306 villagesql/server:percona-8.4_latest
```

**Código-fonte.** Siga [Compilar a Partir do Código-Fonte](/pt-BR/mysql-8.4/stable/source-percona).

Um diretório de dados pertence à base de código que o criou. O VillageSQL recusa
abrir um diretório de dados `mysql-8.4` com um servidor `percona-8.4`, portanto
instale esta compilação em seu próprio diretório em vez de apontá-la para um
diretório existente.

O **VillageSQL Server para MySQL** é um tracking fork extensível e de código aberto, que funciona como um substituto direto para o MySQL.

O VillageSQL Server é construído sobre a base sólida do MySQL, ao mesmo tempo em que introduz um poderoso **Extension Framework**. Esse framework permite que desenvolvedores adicionem funcionalidades inteiramente novas, como novos tipos de dados e funções, sem esperar por lançamentos upstream ou manter forks complexos.

Esta versão do VillageSQL é compatível com o MySQL 8.4.11. A compilação Percona desta versão é baseada no Percona Server para MySQL 8.4.11-11.

## Contribute

- [Server Development Guide](/mysql-8.4/stable/server-development): build, run, test and debug VillageSQL Server.
- [Contributing to VillageSQL](https://github.com/villagesql/villagesql-server/blob/main/CONTRIBUTING.md): how to send a change to the server.
- [Contributor Style Guide](https://github.com/villagesql/villagesql-docs/blob/main/STYLE_GUIDE.md): how to write for these docs.

## Community

- [villagesql.com](https://villagesql.com): the VillageSQL website.
- [GitHub](https://github.com/villagesql/villagesql-server): the server source code.
- [Issues](https://github.com/villagesql/villagesql-server/issues): report a bug or ask for a feature.
- [Discord](https://discord.gg/KSr6whd3Fr): chat with the team and other users.
- [Blog](https://villagesql.com/blog): news and articles.

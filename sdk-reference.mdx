VillageSQL has two SDKs for writing extensions. Both build the same kind of extension, a `.veb` file that you install with `INSTALL EXTENSION`. To write your first extension, start with [Creating Extensions in C++](/mysql-8.4/stable/create) or [Creating Extensions in Rust](/mysql-8.4/stable/rust-sdk).

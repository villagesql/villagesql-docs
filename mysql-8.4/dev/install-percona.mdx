The Percona build ships alongside the MySQL 8.4 build. Install it with the
install script, Docker, a release download, or a source build.

**Install script, at a terminal.** Run the script, then choose **2) Percona 8.4**
at the first question:

```bash
curl -fsSL https://install.villagesql.com | bash
```

**Install script, with no terminal.** In a CI job, a Dockerfile, or an AI agent,
name the codebase and the install method on the `bash` side of the pipe:

```bash
curl -fsSL https://install.villagesql.com | \
  VSQL_CODEBASE=percona-8.4 INSTALL_METHOD=prebuilt bash
```

**Docker.** Images are published for each codebase and architecture:

```bash
docker run -d --name vsql -e MYSQL_ROOT_PASSWORD=<your-password> -p 3306:3306 villagesql/server:percona-8.4_latest
```

**Release download.** The `villagesql-dev-server-percona-8.4_0.0.7-<os>-<arch>.tar.gz`
files on the
[0.0.7 release](https://github.com/villagesql/villagesql-server/releases/tag/release/0.0.7)
cover Linux on x86_64 and aarch64, and macOS on arm64.

**Source.** Build the `percona-8.4` branch, or the `publish/percona-8.4_0.0.7`
tag for the exact code the release shipped — see
[Build from Source](/mysql-8.4/dev/source) for the build steps themselves.

A data directory belongs to the codebase that created it. VillageSQL refuses to
open a `mysql-8.4` data directory with a `percona-8.4` server, so install this
build into its own directory rather than pointing it at an existing one.
